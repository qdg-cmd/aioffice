# 0007 — 키 제공자는 지우지 않고 고급 구역으로 옮긴다

## 맥락

원본은 여러 회사의 API 키를 넣어 쓰는 방식이 중심이었다. 이 제품의 기본은 구독이다. 설정 화면에 키 입력란이 먼저 보이면 처음 쓰는 사람이 무엇을 해야 하는지 헤맨다. 반면 다른 회사의 모델, 로컬 모델, 이미지용 키가 필요한 사람도 있다.

## 결정

설정의 AI 화면은 기본으로 구독 연결만 보여 준다. 키 제공자, 이미지·분석·검색용 키, 자동 호출 스위치는 "고급" 구역 안에 둔다. 기능은 그대로다. 모델 목록에는 구독 제공자를 먼저 보여 주고, 키 제공자는 설정이 채워진 것만 보여 준다.

## 택하지 않은 것

- **키 제공자를 없앤다.** 화면은 단순해지지만 이미지 생성, 영상 분석, 로컬 모델이 함께 사라진다. 원본과의 차이도 크게 벌어진다.
- **지금처럼 나란히 둔다.** 구독으로 쓰려는 사람이 키 입력란 앞에서 멈춘다.

## 결과

- 키 방식 코드를 계속 유지하고 원본의 변경도 받아온다.
- 키를 넣어도 대화에는 자동으로 쓰이지 않는다는 점을 화면과 도움말이 설명해야 한다.
