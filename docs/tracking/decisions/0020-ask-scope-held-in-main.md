# 0020 — 홈의 묻기를 별표 그룹 하나로 좁히는 일은 뒷단이 지킨다

## 맥락

홈의 묻기는 별표를 붙인 파일 전체를 검색하고 읽어 답한다. 문서 묶음(별표 그룹)을 쓰게 되면서, 묻는 범위를 그룹 하나로 좁히는 선택이 필요해졌다. 이미 뒷단에는 "별표 파일만 읽게 막는 검사"가 있다. 좁히기를 화면에서만 하면, 모델이 그룹 밖 파일의 경로를 대고 읽기를 요청했을 때 막을 곳이 없다.

## 결정

- 묻기 칸에 "전체 / 그룹 이름" 선택을 둔다. 기본은 전체다.
- 그룹을 고른 실행마다 화면은 그룹 이름 하나만 넘기고, 뒷단이 그 실행의 불투명한 범위 값을 만든다(`kb:open-scope`). 그 실행의 `kb:*` 호출은 이 값을 싣고, 뒷단은 호출마다 별표 저장소에서 그룹의 파일을 다시 구한다. 화면이 보낸 파일 목록은 믿지 않는다.
- 뒷단이 갖고 있지 않은 범위 값은 거절한다. 범위 없는 질문으로 읽지 않는다. 범위 값은 연 창만 닫을 수 있다.
- 좁히기는 기존 검사(별표 파일만, 저장하지 않은 파일 거절, 디스크와 같은 색인의 발췌만)가 허락한 것을 더 거르기만 한다. 그룹에 속하지 않은 별표 파일은 전체에서만 읽힌다.

## 택하지 않은 것

- **화면에서만 목록을 좁히기.** 모델이 그룹 밖 파일을 읽으려 해도 뒷단이 허락한다.
- **화면이 그룹의 파일 목록을 보내기.** 화면이 보낸 목록을 믿게 되고, 실행 도중 그룹이 바뀌어도 알 수 없다.

## 결과

- 그룹을 고른 실행에서 AI가 그룹 밖 파일을 읽으려 하면 "지식 자료에 없는 경로"로 거절된다.
- 실행 중에 그룹의 파일이 바뀌면 다음 호출부터 바뀐 구성이 적용된다. 파일이 하나도 남지 않은 그룹으로는 묻지 않는다.
- 뒷단은 범위 값을 16개까지만 들고, 넘으면 가장 오래된 것부터 버린다(버려진 값은 거절된다).
