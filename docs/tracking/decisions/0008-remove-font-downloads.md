# 0008 — 글꼴 내려받기를 없애고 파일 설치만 남긴다

## 맥락

원본에는 글꼴 목록에서 글꼴을 골라 내려받는 기능이 있었다. 내려받는 주소는 원본 제작사의 서버다. 이 프로젝트의 설치본에서는 그 서버를 쓸 수 없고, 써서도 안 된다.

## 결정

글꼴 내려받기 목록과 내려받기 기능을 없앤다. 사용자가 가진 글꼴 파일을 설치하는 기능은 남긴다. 설치 파일에 든 글꼴과 PC에 깔린 글꼴은 그대로 쓴다.

## 택하지 않은 것

- **자체 저장소에서 내려받게 한다.** 글꼴마다 라이선스를 확인하고 파일을 올려 관리해야 한다. 지금 범위 밖이다.
- **기능을 그대로 둔다.** 누르면 실패하는 버튼이 남고, 원본 제작사의 서버에 요청이 간다.

## 결과

- 한글 글꼴을 더 쓰려면 사용자가 글꼴 파일을 구해 설치해야 한다. (2026-10-14 덧붙임: 슬라이드 디자인 템플릿용 한글 글꼴 6개 패밀리가 설치 파일에 들어갔다. 내려받기는 여전히 없다. 0013 참고.)
- 내려받은 글꼴을 쓴 예전 문서를 열면 기존의 글꼴 대체 동작을 따른다.
