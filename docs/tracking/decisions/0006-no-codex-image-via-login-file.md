# 0006 — Codex 구독 이미지 생성은 로그인 파일을 건드리지 않는 방법으로만 넣는다

## 맥락

사용자는 Codex 구독으로 이미지를 만들고 싶어 했고, 이전에 쓰던 방법이 있었다. 그 방법은 Codex의 로그인 파일을 임시 폴더로 복사해 따로 실행한다. OpenAI는 그 파일을 비밀번호처럼 다루라고 한다. 이 앱은 여러 사람에게 배포된다.

## 결정

로그인 파일을 읽거나 복사하지 않는 방법으로만 구현한다. 그 방법으로 끝까지 확인되지 않으면 넣지 않고, 이미지 생성은 키 방식만 남긴다. 선택 목록에도 보이지 않게 한다.

지금 상태: 안전한 실행 방법은 이미지 단계 직전까지 확인했으나, 확인에 쓴 계정의 요금제에 이미지 도구가 없어 끝까지 확인하지 못했다. 그래서 넣지 않았다.

## 택하지 않은 것

- **로그인 파일을 복사하는 방법을 쓴다.** 동작하는 것은 알지만, 배포용 앱이 사용자의 로그인 정보를 복사하게 된다. 이 프로젝트가 가장 먼저 지키는 선을 넘는다.
- **확인되지 않은 채로 넣고 실패하면 키 방식으로 넘긴다.** 사용자가 고르지 않은 요금 경로로 가게 된다.

## 결과

- 이미지를 만들려면 이미지 제공자의 키가 있어야 한다. "키 없이"라는 약속이 이미지에는 미치지 않는다.
- 이미지 제공자가 없으면 슬라이드는 검색으로 찾은 사진을 쓴다.
- 다시 시도하려면 이미지 도구가 있는 요금제의 계정이 필요하다.
