# 0002 — 요금이 나가는 연결로 스스로 가지 않고, 막히면 버튼으로 넘어간다

## 맥락

이 제품의 약속은 "API 키 없이, 이미 내고 있는 구독으로"다. 그런데 앱에는 키 제공자도 남아 있고, 구독 프로그램이 API 키나 종량제 계정으로 로그인돼 있을 수도 있다. 구독 한도가 차거나 로그인이 풀렸을 때 다른 연결로 자동으로 이어 가면 편하다.

## 결정

- 자동 선택(`auto`)은 구독 로그인이 확인된 제공자만 고른다. 키 제공자와 종량 로그인은 사용자가 직접 골랐을 때만 대화에 쓰인다.
- 종량 로그인은 경고를 보여 주고 사용자가 "그래도 사용"을 고른 뒤에만 고를 수 있다. 로그인 방식을 알 수 없으면 종량으로 본다.
- 실행 중 막히면 멈추고 이유를 보여 준다. 다른 구독이 연결돼 있으면 "…로 계속" 버튼을 보여 준다. 키 제공자로 넘어가는 버튼은 없다.

## 택하지 않은 것

- **막히면 다음 제공자로 자동 전환한다.** 사용자가 모르는 사이 다른 구독의 한도를 쓰거나 요금이 나간다. 답의 품질과 말투도 도중에 달라진다.
- **종량 로그인을 구독과 같게 다룬다.** 프로그램이 "로그인됨"이라고 답해도 그것이 구독인지 API 키인지에 따라 돈이 나가는지가 갈린다. 구분하지 않으면 약속이 깨진다.
- **키 제공자를 아예 없앤다.** 요금 경로가 사라져 규칙은 단순해지지만, 이미지 생성·영상 분석·로컬 모델 연결이 함께 사라진다.

## 결과

- 구독이 하나뿐인 사용자는 한도가 차면 풀릴 때까지 AI를 쓰지 못한다. 앱이 대신 해 주는 것은 풀리는 시각을 보여 주는 것뿐이다.
- 키 제공자만 설정한 사용자는 직접 고르기 전까지 "연결 필요"를 본다.
- 프로그램에 넘기는 환경에서 요금 경로를 바꾸는 변수를 빼야 한다. 상태 확인 뒤에 로그인 방식이 바뀌는 경우도 막아야 하는데, 지금은 Codex만 실행 직전에 다시 확인한다.
