# 0027 — 변경 내용 추적이 든 한글 문서는 지금의 내용으로 열고, 저장하면 추적 기록 없이 저장한다

[0025](0025-hwp-no-save-with-tracked-changes.md)을 대신한다.

## 맥락

0025에서는 변경 내용 추적이 든 `.hwp`를 저장하지 않기로 했다. rhwp가 두 번째 본문(`ViewText`)을 문서로 읽어 지운 글까지 보이고, 저장하면 한컴 한글이 열지 못했기 때문이다. 저장소 주인이 이것을 상위 프로젝트에 미루지 말고 이 프로그램에서 고치라고 했다(2026-10-14).

다시 들여다보니(한컴 한글 2024, 샘플의 추적 문서 4개):

- 한글은 본문(`BodyText`)에 지금 읽히는 대로의 문서를 두고, 두 번째 본문에 지운 글과 바뀌기 전의 글까지 표시된 문서를 둔다. 한 문서의 본문은 3,436자, 두 번째 본문은 10,010자였다.
- rhwp는 두 번째 본문이 있으면 그것을 읽는다. 그래서 지운 글이 보통 글처럼 보이고, 한글이 6쪽으로 보이는 문서가 18쪽이 된다.
- 두 번째 본문과 머리의 추적 표시를 뺀 파일을 엔진에 주면 엔진은 본문을 읽는다. 쪽 수가 한글과 같거나(6, 12) 거의 같았다(317 대 315, 202 대 206). 한글은 그 파일을 열고, 첫 쪽을 원본과 같게 그린다.
- 그렇게 연 문서를 저장한 것(그대로 / 고쳐서)은 한글이 열고 원본과 쪽 수가 같다. 고쳐서 저장한 것 하나는 열리지 않았는데, 수식 개체에 딸린 목록을 엔진이 빠뜨리는 다른 문제였다(`findings.md`).
- 0025에서 "두 번째 본문만 빼도 한글이 거절한다"고 본 것은 컨테이너를 고쳐 쓰는 방식이 디렉터리를 망가뜨린 탓이었다. 라이브러리의 지우기 호출이 자기 표식 스트림을 넣고, 파일에서 읽은 항목 사이의 연결을 그대로 두어서였다.

## 결정

- 메인 프로세스가 `.hwp`를 읽어 줄 때 추적 문서이면(머리의 표시와 두 번째 본문이 둘 다 있으면) 두 번째 본문과 머리의 추적 표시를 뺀 파일을 편집기에 준다(`apps/hwp/src/main/tracked-changes.ts`의 `withoutTrackedChanges`). 디스크의 파일은 건드리지 않는다.
  - 두 번째 본문의 항목은 디렉터리에서 그대로 빼고, 항목 사이의 연결은 라이브러리가 새로 짓게 한다. 라이브러리의 지우기 호출은 쓰지 않는다.
  - 결과를 다시 읽어, 보통 `.hwp`이고(두 번째 본문·암호·배포용이 아니고) 본문 구역들이 원래 바이트 그대로인지 본다. 아니면 0025처럼 저장을 거절한다(`saveTracked`).
- 편집기는 지금의 내용을 보여 주고, 열 때 "변경 내용 추적이 든 문서이고, 화면에는 지금의 내용만 보이며, 저장하면 변경 기록 없이 이 내용으로 저장된다"고 알린다(`openedTracked`, 닫을 때까지 남는다).
- 저장은 다른 문서와 같다. 처음 덮어쓸 때 원본이 `.bak`으로 남으므로 추적 기록이 든 원본은 거기 있다.
- 바탕쪽·메모 다시 붙이기(0024)와 필드 종류 되돌리기(0026)는 편집기에 준 파일을 기준으로 한다.

## 택하지 않은 것

- **저장을 계속 거절한다(0025).** 이런 문서는 이 앱에서 고쳐도 쓸 수 없다.
- **추적 기록을 지키며 저장한다.** 엔진이 추적 기록과 두 번째 본문을 쓰지 않는다. 원본의 두 번째 본문을 다시 넣으면 본문과 맞지 않는 파일이 된다(0025에서 쪽 수가 6에서 15로 바뀐 문서가 있었다).
- **두 번째 본문을 그대로 읽게 두고 지운 글을 걸러낸다.** 엔진이 추적 표시를 읽지 않아 무엇이 지운 글인지 알 수 없다.

## 결과

- 추적 문서를 열면 한글에서 "변경 내용 반영"으로 본 것과 같은 글이 보인다. 지운 글은 보이지 않는다.
- 저장하면 추적 기록(누가 무엇을 바꿨는지)이 사라진다. 원본은 `.bak`에 남는다.
- AI도 지금의 내용만 읽고 고친다.
- `.hwpx`의 변경 추적은 이 결정에 들지 않는다.
- 확인(한컴 한글 2024): 샘플의 추적 문서 4개를 이렇게 연 것이 모두 한글에서 원본과 같은 쪽 수로 열렸다. 빌드한 앱에서 둘을 열어 알림을 보고, 입력하고 저장한 파일이 한글에서 열렸다(6쪽 → 6쪽, 12쪽 → 넣은 줄 때문에 13쪽).
