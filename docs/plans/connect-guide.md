# AI 연결 도우미 계획

상태: **진행 중**(2026-10-21). "정한 것"은 결정 기록 [0047](../tracking/decisions/0047-connect-guide-and-update-button.md)에 옮겼다.

## 1. 무엇을 하려는가

AI를 잘 모르는 사람도 연결을 끝까지 해내게 한다. 지금의 연결 화면은 구독 프로그램을 아는 사람에게 맞춰져 있다.

2026-10-21 시험 사용자 신고(0.12.x)에서 본 화면:

- Claude 카드는 "로그인하는 중…"에서 멈춰 있었고, 브라우저가 열렸는지 사용자는 몰랐다. 다음에 할 일은 작은 회색 링크 하나였다.
- 쓰지도 않을 Codex 카드에는 빨간 오류("버전이 낮습니다. 업데이트한 뒤…")가 함께 떠서, 사용자는 "AI 어떤 것도 연결이 안 된다"고 느꼈다. 업데이트 방법은 화면에 없었다.
- Claude 쪽은 유료 구독(Pro·Max)이 있어야 한다는 말이 어디에도 없었다.
- 구독이 없는 사람의 가장 쉬운 길(무료 AI)은 맨 아래 회색 글이었다.

## 2. 정한 것

1. **먼저 묻는다.** 아무것도 연결되지 않았으면 "지금 쓰는 AI가 있나요?"에 세 가지 길로 답하게 한다. Claude 유료 구독 / ChatGPT 계정(Codex로 연결) / 없음(무료 AI). 고른 길 하나만 펼치고 나머지는 보이지 않는다. "다른 방법 고르기"로 돌아간다.
2. **"ChatGPT"라는 이름은 고르는 화면의 설명 글에만 쓴다**(저장소 주인 결정, 2026-10-21). 로고는 쓰지 않는다. 카드 제목과 모델 선택기의 이름은 지금처럼 `Codex`다.
3. **단계를 보여 준다.** 고른 구독 길에 `설치 → 로그인 → 연결됨`을 보이고 지금 단계를 강조한다. 각 단계의 버튼은 하나이고, 누르면 무엇이 일어나는지 한 줄로 먼저 말한다.
4. **로그인이 길어지면 도와준다.** 브라우저 로그인이 25초 넘게 끝나지 않으면 "브라우저가 안 열렸거나 코드가 보이나요?" 안내와 함께 로그인 창 버튼을 일반 버튼으로 올린다. 로그인 창 안내에는 "붙여 넣어도 글자가 보이지 않는 것이 정상"이라고 적는다. 로그인 중에는 "로그인 취소"가 있다.
5. **업데이트 버튼**(저장소 주인 결정, 2026-10-21). 프로그램 버전이 낮다는 오류 카드에 "업데이트"를 둔다. 그 회사의 공식 업데이트 명령을 눈에 보이는 새 창에서 실행한다. 명령은 고정된 글이고 사용자 입력이 섞이지 않는다(4절).
6. **도움 요청용 정보 복사.** 연결되지 않은 동안 도우미 아래에 "도움 요청용 정보 복사"가 있다. 화면 상태(제공자별 상태, 오류 종류, 프로그램 버전)와 앱 정보만 복사한다. 계정, 경로, 프로그램이 출력한 글은 넣지 않는다.

## 3. 어디에 나오는가

| 자리                                                            | 지금                             | 바뀐 뒤                                                             |
| --------------------------------------------------------------- | -------------------------------- | ------------------------------------------------------------------- |
| AI 창의 "AI를 쓰려면 먼저 연결하세요"(편집기 9곳, 홈 질문 패널) | 두 카드 + 맨 아래 무료 안내      | 고르기 → 고른 길의 단계와 카드. 무료를 고르면 설정 → AI가 열린다    |
| 첫 실행 안내의 연결 단계                                        | 두 카드 + Codex 안내 + 무료 카드 | 고르기 → 고른 길. 무료를 고르면 무료 카드가 그 자리에 펼쳐진다      |
| 설정 → AI                                                       | 두 카드(계정·계정 버튼 포함)     | 그대로 두 카드. 업데이트·로그인 취소·로그인 창 올리기는 같이 받는다 |
| 고른 제공자를 쓸 수 없을 때의 안내                              | 그 제공자 카드 하나              | 그대로. 카드가 받는 개선(4, 5)은 같이 받는다                        |

어느 하나라도 연결되면 고르는 화면은 나오지 않는다. 첫 실행 안내에서는 연결된 길이 "연결됨" 단계로 펼쳐진다.

## 4. 업데이트 명령

| 프로그램 | 찾은 곳                                          | 명령                                          |
| -------- | ------------------------------------------------ | --------------------------------------------- |
| Claude   | 어디든                                           | 찾은 실행 파일에 `update`                     |
| Codex    | npm 전역 설치(`node_modules\@openai\codex` 아래) | `npm install -g @openai/codex@latest`         |
| Codex    | winget                                           | `winget upgrade --id OpenAI.Codex -e`         |
| Codex    | 그 밖(데스크톱 앱의 사본, 사용자가 지정한 경로)  | 실행하지 않는다. 공식 설치 안내 페이지를 연다 |

- 창은 설치 버튼처럼 `start`로 연 새 PowerShell이고 끝나도 닫히지 않는다(`-NoExit`). 결과를 사용자가 본다.
- Claude는 이름(`claude`)으로 부르지 않고 앱이 찾은 실행 파일을 부른다. 한 PC에 사본이 여럿이면 이름은 다른 사본을 가리킬 수 있다. 경로는 명령 글에 끼워 넣지 않고 환경변수로 값만 넘긴다(로그인 창과 같은 방식).
- Windows에서만 한다. 다른 체제에서는 버튼이 없다.
- 앱은 기다리지 않는다. 사용자가 앱으로 돌아오면 다시 확인한다(설치와 같다).

## 5. 화면 규칙(순수 함수)

- `aiConnectGuideView(statuses, chosen)` — 고르는 화면을 보일지, 어느 길이 펼쳐졌는지, 각 길 옆의 짧은 상태.
  - 연결된(`ready`) 제공자가 있으면 그 길이 펼쳐진다.
  - 로그인하는 중인 제공자가 있으면 그 길이 펼쳐진다.
  - 그 밖에는 사용자가 고른 길, 고르지 않았으면 고르는 화면.
- `aiConnectStepsView(status)` — 세 단계와 지금 단계. `not-installed`와 버전이 낮은 `error`는 설치 단계, `signed-out`·로그인 중·`metered`·그 밖의 `error`는 로그인 단계, `ready`는 연결됨. `checking`은 지금 단계가 없다.
- `aiSubscriptionCardView`에 `signingInStalled`(25초가 지났는지)와 `update`·`cancelLogin`을 받을 수 있는지가 더해진다.
- `aiConnectInfoText(statuses, app)` — 복사할 정보. 계정과 경로는 상태에 있어도 넣지 않는다.

## 6. 뒷단

- 창구 두 개를 더한다. `ai:subscription-update`(업데이트 창 띄우기), `ai:subscription-cancel-login`(앱이 띄운 로그인 끝내기). 둘 다 제공자 하나를 받고 `SubscriptionLaunchResult`로 답한다.
- 로그인 취소는 진행 중인 로그인의 프로세스 나무를 끝낸다. 끝나면 지금처럼 상태를 다시 확인한다. 진행 중인 로그인이 없으면 아무것도 하지 않고 `ok`다.
- 편집기 9곳의 preload와 연결 훅에 두 동작을 더한다. 카드는 두 콜백을 받았을 때만 그 버튼을 그린다. 예전 preload에서는 버튼이 없을 뿐 깨지지 않는다.

## 7. 하지 않는 것

- 앱 안에서 로그인 화면을 만들거나 코드를 받아 넘기지 않는다. 지금과 같다.
- 사용자의 구독 요금제를 앱이 알아내지 않는다. "유료 구독이 있어야 한다"는 고르기 전에 알리는 글이다.
- 고른 길을 저장하지 않는다. 화면을 닫으면 다시 묻는다. 진행 중인 것(로그인 중, 연결됨)은 상태로 다시 펼쳐진다.
- 설정 → AI의 카드 배치는 바꾸지 않는다. 그 화면은 이미 아는 사람이 관리하는 곳이다.

## 8. 확인

- 순수 함수와 카드의 단위 시험(`packages/ui/tests`), 뒷단의 업데이트 명령·취소 시험(`packages/ai-provider/tests`, 가짜 실행).
- 21개 언어 키와 자리 표시.
- 빌드한 앱을 임시 데이터 폴더로 띄워 세 자리(편집기 AI 창, 첫 실행 안내, 설정)를 밝은·어두운 테마로 찍어 본다. 실제 로그인과 업데이트는 누르지 않는다(사용자의 PC 프로그램을 바꾼다).
