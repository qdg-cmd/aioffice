# Google Drive

Hubungkan Google Drive Anda untuk membuka dan mengedit file Drive di GenOffice. Saat Anda menyimpan, file kembali ke Drive. Anda juga dapat membiarkan AI di editor mencari dan membaca file di Drive Anda.

## Menghubungkan

1. Buka **Pengaturan ▸ Integrasi** lalu klik **Hubungkan Google Drive**.
2. Browser membuka halaman login Google. Masuk dan izinkan akses.
3. Kembali ke GenOffice. Kartu menampilkan akun yang terhubung.

Login disimpan di PC ini, dienkripsi dengan perlindungan yang disediakan Windows untuk akun Anda. Jika PC ini tidak dapat mengenkripsinya, koneksi hanya bertahan sampai Anda menutup aplikasi.

## Membuka file Drive

- Di Beranda, klik **Google Drive** di bilah samping. Beralih antara **Drive Saya**, **Dibagikan kepada saya**, dan **Terbaru**, atau cari berdasarkan nama dan isi.
- Klik file untuk membukanya di editornya. File yang tidak dapat dibuka GenOffice tampil abu-abu.
- Google Dokumen, Spreadsheet, dan Slide dibuka sebagai file Word, Excel, dan PowerPoint.

## Menyimpan kembali ke Drive

- Simpan seperti biasa. Sesaat kemudian file diunggah ke Drive.
- Jika seseorang mengubah file di Drive setelah Anda membukanya, GenOffice bertanya apakah akan menimpanya di Drive, menyimpan salinan ke Drive, atau menyimpan perubahan Anda di PC ini saja.
- File yang hanya dapat Anda lihat disimpan ke Drive sebagai salinan, atau disimpan di PC ini.
- Dokumen Google dibiarkan apa adanya. Perubahan Anda disimpan sebagai file Office di folder yang sama.
- Jika pengunggahan gagal, perubahan Anda tetap di PC ini dan GenOffice mencoba lagi, juga saat aplikasi dimulai berikutnya.

## AI dan Drive Anda

- Di panel AI editor Word, Excel, PowerPoint, HTML, peta pikiran, dan Hangul, **Lampirkan dari Google Drive** (di samping tombol lampiran) membuka jendela untuk mencentang file atau folder Drive. File itu dilampirkan seperti file dari PC ini; folder membawa hingga 20 file di dalamnya.
- Selama **Izinkan AI mencari dan membaca file di Drive** aktif (aktif setelah terhubung), AI di setiap editor dapat mencari di Drive dan membaca file. Contoh: "Cari notulen rapat bulan lalu di Drive dan buat ringkasannya."
- Yang dibaca AI dikirim ke penyedia AI yang Anda gunakan. Bagian yang disembunyikan dari AI tetap tersembunyi.
- AI tidak dapat mengubah, menghapus, atau membagikan file Drive.
- Setelah percakapan berisi sesuatu yang dibaca dari Drive, pencarian web, pencarian gambar, pembacaan halaman melalui alamat web, dan gambar melalui alamat web berhenti berfungsi di percakapan itu. Mulai percakapan baru untuk menggunakannya lagi.

## Memutuskan koneksi

Klik **Putuskan** di **Pengaturan ▸ Integrasi**. GenOffice menghapus login dari PC ini dan meminta Google mencabut aksesnya. Salinan file yang sudah ada di PC ini tetap tersimpan.
