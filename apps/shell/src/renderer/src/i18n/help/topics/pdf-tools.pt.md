# Ferramentas de PDF

Uma janela para as tarefas comuns com PDF que começa pela tarefa. O resultado é sempre salvo como um novo arquivo e o original não muda. As ferramentas desta janela funcionam só neste PC e não usam IA.

## Como funciona

1. Na tela inicial, clique no cartão **Ferramentas de PDF**. Uma janela separada se abre.
2. Escolha uma tarefa, os arquivos de que ela precisa e as opções, e clique em **Salvar como novo arquivo**.
3. Depois de salvar, **Abrir em uma aba** mostra o resultado e **Mostrar na pasta** abre a pasta dele.

## As ferramentas

| Grupo                   | Ferramentas                                                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| Organizar páginas       | Mesclar PDF, Dividir PDF, Extrair páginas como PDF, Inverter ordem, Girar todas, Remover páginas em branco   |
| Preparar para impressão | Preparar para frente e verso, Combinar páginas, Tamanho da página, Dividir páginas                           |
| Decorar                 | Adicionar um fundo                                                                                           |
| Limpar                  | Remover anotações                                                                                            |
| Converter               | Imagens para PDF, Salvar como texto                                                                          |
| Tamanho e segurança     | Reduzir tamanho, Adicionar senha, Remover senha, Reparar arquivo                                             |
| No editor de PDF        | Marca d'água e cabeçalho/rodapé, Recortar páginas, Exportar imagens, Converter PDF, Editar, assinar, ocultar |

Os cartões de **No editor de PDF** abrem o PDF escolhido em uma aba do editor. Escolha ali a função na faixa de opções.

## Bom saber

- Não é possível salvar sobre um arquivo de origem nem sobre um arquivo aberto com alterações não salvas.
- Um PDF protegido por senha só funciona nas outras ferramentas depois de **Remover senha**. Um arquivo cuja senha você não conhece não pode ser aberto.
- **Reparar arquivo** recupera só as partes que ainda podem ser lidas. Abra o novo arquivo e confira se não falta nenhuma página.
- **Remover páginas em branco** só mostra candidatas. Só as páginas escolhidas são removidas, e uma página com um único caractere nunca é candidata.
- **Remover anotações** mantém os campos de formulário e só remove links quando você os marca. O conteúdo das anotações removidas não fica no novo arquivo.
- **Salvar como texto** lê apenas a camada de texto. Páginas cujo texto é uma imagem, como as digitalizadas, ficarão vazias.

## Experimente para

| Situação                                                                             | Ferramentas                                     |
| ------------------------------------------------------------------------------------ | ----------------------------------------------- |
| Imprimir vários documentos em frente e verso de uma vez, cada um começando na frente | Preparar para frente e verso → Combinar páginas |
| Um documento digitalizado saiu em ordem inversa ou com páginas deitadas              | Inverter ordem, Girar todas                     |
| Há páginas em branco entre as de um lote digitalizado                                | Remover páginas em branco                       |
| Aplicar o papel timbrado de uma empresa ou instituição em todas as páginas           | Adicionar um fundo                              |
| Limpar os comentários antes de enviar um documento revisado                          | Remover anotações                               |
| Entregar várias fotos como um único PDF                                              | Imagens para PDF                                |
| Reaproveitar o texto de um PDF em outro documento                                    | Salvar como texto                               |
| Um PDF é grande demais para anexar a um e-mail                                       | Reduzir tamanho                                 |
| Um PDF cujo download parou no meio não abre                                          | Reparar arquivo                                 |
