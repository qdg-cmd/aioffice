# Strumenti PDF

Una finestra per i lavori più comuni con i PDF, che parte dal lavoro da fare. Il risultato viene sempre salvato come nuovo file e l’originale non cambia. Gli strumenti di questa finestra lavorano solo su questo PC e non usano l’IA.

## Come funziona

1. Nella Home, fai clic sulla scheda **Strumenti PDF**. Si apre una finestra separata.
2. Scegli un lavoro, i file che servono e le opzioni, poi fai clic su **Salva come nuovo file**.
3. Dopo il salvataggio, **Apri in una scheda** mostra subito il risultato e **Mostra nella cartella** apre la sua cartella.

## Gli strumenti

| Gruppo                 | Strumenti                                                                                                        |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Organizza pagine       | Unisci PDF, Dividi PDF, Estrai pagine come PDF, Inverti ordine, Ruota tutte, Rimuovi pagine bianche              |
| Prepara per la stampa  | Prepara per fronte-retro, Combina pagine, Dimensioni pagina, Dividi pagine                                       |
| Decora                 | Aggiungi uno sfondo                                                                                              |
| Pulisci                | Rimuovi annotazioni                                                                                              |
| Converti               | Immagini in PDF, Salva come testo                                                                                |
| Dimensioni e sicurezza | Riduci dimensioni, Aggiungi password, Rimuovi password, Ripara file                                              |
| Nell’editor PDF        | Filigrana e intestazione/piè di pagina, Ritaglia pagine, Esporta immagini, Converti PDF, Modifica, firma, oscura |

Le schede di **Nell’editor PDF** aprono il PDF scelto in una scheda dell’editor. Lì scegli il comando nella barra multifunzione.

## Da sapere

- Non puoi salvare su un file di origine né su un file aperto con modifiche non salvate.
- Un PDF protetto da password si può usare negli altri strumenti solo dopo **Rimuovi password**. Un file di cui non conosci la password non si può aprire.
- **Ripara file** recupera solo le parti ancora leggibili. Apri il nuovo file e controlla che non manchi nessuna pagina.
- **Rimuovi pagine bianche** mostra solo candidate. Vengono rimosse solo le pagine scelte, e una pagina con anche un solo carattere non è mai candidata.
- **Rimuovi annotazioni** mantiene i campi modulo e rimuove i collegamenti solo se li selezioni. Il contenuto delle annotazioni rimosse non rimane nel nuovo file.
- **Salva come testo** legge solo il livello di testo. Le pagine il cui testo è un’immagine, come quelle scansionate, resteranno vuote.

## Prova per

| Situazione                                                                      | Strumenti                                 |
| ------------------------------------------------------------------------------- | ----------------------------------------- |
| Stampare più documenti fronte-retro in una volta, ognuno a partire da un fronte | Prepara per fronte-retro → Combina pagine |
| Un documento scansionato è in ordine inverso o ha pagine coricate               | Inverti ordine, Ruota tutte               |
| Tra le pagine di un fascicolo scansionato ci sono pagine bianche                | Rimuovi pagine bianche                    |
| Mettere la carta intestata di un’azienda o di un ente su ogni pagina            | Aggiungi uno sfondo                       |
| Ripulire i commenti prima di inviare un documento rivisto                       | Rimuovi annotazioni                       |
| Consegnare più foto come un unico PDF                                           | Immagini in PDF                           |
| Riutilizzare il testo di un PDF in un altro documento                           | Salva come testo                          |
| Un PDF è troppo grande da allegare a un’e-mail                                  | Riduci dimensioni                         |
| Un PDF il cui download si è interrotto non si apre                              | Ripara file                               |
