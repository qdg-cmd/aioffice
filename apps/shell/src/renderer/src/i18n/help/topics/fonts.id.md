# Font: font sistem dan memasang file font

## Daftar font

Kontrol font berada di tab Beranda tiap editor.

Pemilih font tiap editor menggabungkan: font yang terpasang di komputer + kandidat umum platform (keluarga Windows dan macOS yang lazim, baik Latin maupun CJK, termasuk nama terlokalisasi yang dilaporkan sistem untuk font CJK). Ketika sistem dapat membuat daftar font lokal, daftarnya dikelompokkan menurut apa yang benar-benar ada; kalau tidak, daftar itu turun ke daftar kandidat lengkap.

Setiap font dalam daftar sudah terpasang di PC ini atau disertakan bersama aplikasi. Tidak ada yang diunduh.

## Memasang file font (Slides)

- Di bagian bawah daftar font Slides, **Instal file font…** menambahkan file font yang sudah Anda miliki: .ttf, .otf, .ttc, atau .otc.
- File-file itu disalin ke folder font milik aplikasi. Font tersebut hanya berfungsi di aplikasi ini; tidak ada yang dipasang ke sistem. Presentasi yang sedang terbuka ditata ulang dengan font baru itu.
- Bila file-file itu berisi satu keluarga font saja, font itu langsung diterapkan pada apa yang sedang Anda pilih.
- Font yang dipasang dengan cara ini tidak muncul dalam daftar. Untuk memakainya nanti, ketikkan namanya di kotak font.
- Beberapa bobot dari satu keluarga dapat dipasang berdampingan.
- Aplikasi tidak punya perintah untuk menghapus font yang dipasang dengan cara ini.

## Font yang diperlukan dokumen tetapi tidak Anda miliki

- Dokumen yang memakai font yang belum terpasang ditampilkan dengan font pengganti.

## Tipografi CJK

- Font CJK di Docs mendapat kompresi tanda baca dan aturan pemenggalan baris kinsoku yang selaras dengan Word (lihat bab Docs).
