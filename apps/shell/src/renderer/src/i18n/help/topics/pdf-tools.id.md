# Alat PDF

Jendela untuk tugas PDF sehari-hari yang dimulai dari tugasnya. Hasilnya selalu disimpan sebagai file baru dan file asli tidak berubah. Alat di jendela ini hanya bekerja di PC ini dan tidak memakai AI.

## Cara kerjanya

1. Di Beranda, klik kartu **Alat PDF**. Jendela terpisah akan terbuka.
2. Pilih tugas, file yang dibutuhkan, dan opsinya, lalu klik **Simpan sebagai file baru**.
3. Setelah disimpan, **Buka di tab** langsung menampilkan hasilnya dan **Tampilkan di folder** membuka foldernya.

## Daftar alat

| Grup                | Alat                                                                                                      |
| ------------------- | --------------------------------------------------------------------------------------------------------- |
| Atur halaman        | Gabungkan PDF, Pisahkan PDF, Ekstrak halaman sebagai PDF, Balik urutan, Putar semua, Hapus halaman kosong |
| Persiapan cetak     | Siapkan cetak bolak-balik, Gabung halaman, Ukuran halaman, Pisahkan halaman                               |
| Hias                | Tambahkan latar                                                                                           |
| Rapikan             | Hapus anotasi                                                                                             |
| Konversi            | Gambar ke PDF, Simpan sebagai teks                                                                        |
| Ukuran dan keamanan | Perkecil ukuran, Tambah kata sandi, Hapus kata sandi, Perbaiki file                                       |
| Di editor PDF       | Tanda air & header/footer, Pangkas halaman, Ekspor gambar, Konversi PDF, Edit, tanda tangan, sensor       |

Kartu di grup **Di editor PDF** membuka PDF yang dipilih di tab editor. Pilih perintahnya di pita di sana.

## Perlu diketahui

- Anda tidak bisa menyimpan di atas file sumber atau file yang terbuka dengan perubahan yang belum disimpan.
- PDF yang dilindungi kata sandi baru bisa dipakai di alat lain setelah **Hapus kata sandi**. File yang kata sandinya tidak Anda ketahui tidak bisa dibuka.
- **Perbaiki file** hanya mengembalikan bagian yang masih bisa dibaca. Buka file baru dan periksa apakah ada halaman yang hilang.
- **Hapus halaman kosong** hanya menampilkan kandidat. Hanya halaman yang Anda pilih yang dihapus, dan halaman dengan satu huruf pun tidak pernah menjadi kandidat.
- **Hapus anotasi** mempertahankan kolom formulir dan hanya menghapus tautan jika Anda mencentangnya. Isi anotasi yang dihapus tidak tersisa di file baru.
- **Simpan sebagai teks** hanya membaca lapisan teks. Halaman yang teksnya berupa gambar, seperti halaman pindaian, akan kosong.

## Cocok untuk

| Situasi                                                                            | Alat                                       |
| ---------------------------------------------------------------------------------- | ------------------------------------------ |
| Mencetak beberapa dokumen bolak-balik sekaligus, masing-masing mulai di sisi depan | Siapkan cetak bolak-balik → Gabung halaman |
| Dokumen pindaian urutannya terbalik atau halamannya miring ke samping              | Balik urutan, Putar semua                  |
| Ada halaman kosong di sela-sela halaman berkas pindaian                            | Hapus halaman kosong                       |
| Memasang kop surat perusahaan atau lembaga di setiap halaman                       | Tambahkan latar                            |
| Merapikan komentar sebelum mengirim dokumen yang sudah ditinjau                    | Hapus anotasi                              |
| Mengumpulkan beberapa foto sebagai satu PDF                                        | Gambar ke PDF                              |
| Memakai teks PDF di dokumen lain                                                   | Simpan sebagai teks                        |
| PDF terlalu besar untuk dilampirkan ke email                                       | Perkecil ukuran                            |
| PDF yang unduhannya terputus tidak bisa dibuka                                     | Perbaiki file                              |
