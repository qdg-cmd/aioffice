# PDF 工具

這個視窗從要做的事開始，處理常見的 PDF 工作。結果一律另存為新檔案，原檔案不會改變。此視窗中的工具只在這台電腦上處理，不使用 AI。

## 使用步驟

1. 在首頁按一下 **PDF 工具** 卡片，會開啟一個獨立的視窗。
2. 選擇工作，選擇所需的檔案並設定選項，然後按一下 **另存為新檔案**。
3. 儲存後，用 **在分頁中開啟** 立即查看結果，或用 **開啟所在資料夾** 開啟檔案所在位置。

## 工具列表

| 群組            | 工具                                                                     |
| --------------- | ------------------------------------------------------------------------ |
| 整理頁面        | 合併 PDF、拆分 PDF、擷取頁面為 PDF、倒序排列、全部旋轉、尋找並刪除空白頁 |
| 列印準備        | 雙面列印對齊、合併頁面、頁面大小、拆分頁面                               |
| 裝飾            | 疊加背景                                                                 |
| 整理            | 批次刪除註解                                                             |
| 轉換            | 圖片轉 PDF、儲存為文字檔                                                 |
| 大小與安全      | 縮減大小、加上密碼、移除密碼、修復檔案                                   |
| 在 PDF 編輯器中 | 浮水印與頁首頁尾、裁剪頁面、匯出圖片、PDF 轉換、編輯、簽名、遮蔽         |

**在 PDF 編輯器中** 群組中的卡片會在編輯器分頁中開啟所選 PDF。請在功能區中選擇相應功能。

## 須知

- 不能儲存到原檔案，也不能儲存到帶有未儲存變更且正在開啟的檔案。
- 有密碼保護的 PDF 需要先用**移除密碼**移除密碼，才能在其他工具中使用。不知道密碼的檔案無法開啟。
- **修復檔案**只能找回仍可讀取的部分。請開啟新檔案，確認沒有缺頁。
- **尋找並刪除空白頁** 只列出候選頁面。只刪除您選取的頁面，有任何文字的頁面都不會成為候選。
- **批次刪除註解** 不會刪除表單欄位，連結只有在勾選時才刪除。已刪除註解的內容不會留在新檔案中。
- **儲存為文字檔** 只讀取文字層。文字以圖片形式存在的頁面（如掃描頁）將會是空白。

## 可以這樣用

| 情況                                     | 使用的工具              |
| ---------------------------------------- | ----------------------- |
| 一次雙面列印多份文件，每份都要從正面開始 | 雙面列印對齊 → 合併頁面 |
| 掃描的文件順序顛倒，或頁面橫了過來       | 倒序排列、全部旋轉      |
| 掃描的一疊文件中夾著空白頁               | 尋找並刪除空白頁        |
| 為每一頁加上公司或機構的信紙背景         | 疊加背景                |
| 傳送審閱完的文件前整理附註               | 批次刪除註解            |
| 把多張照片合成一個 PDF 繳交              | 圖片轉 PDF              |
| 把 PDF 中的文字用到其他文件裡            | 儲存為文字檔            |
| PDF 太大，無法當作郵件附件寄出           | 縮減大小                |
| 下載中斷的 PDF 打不開                    | 修復檔案                |
