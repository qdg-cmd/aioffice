# แบบอักษร: แบบอักษรของระบบและการติดตั้งไฟล์แบบอักษร

## รายการแบบอักษร

ตัวควบคุมแบบอักษรอยู่บนแท็บหน้าแรกของตัวแก้ไขแต่ละตัว

ตัวเลือกแบบอักษรของแต่ละตัวแก้ไขรวมไว้ด้วยกัน: แบบอักษรที่ติดตั้งในเครื่อง + แบบอักษรที่มักมีในแต่ละแพลตฟอร์ม (ตระกูลที่พบบ่อยของ Windows และ macOS ทั้งภาษาตะวันตกและจีน ญี่ปุ่น เกาหลี รวมถึงชื่อที่เป็นภาษาท้องถิ่นของแบบอักษรจีน ญี่ปุ่น เกาหลี ในระบบของตัวเอง) เมื่อระบบสามารถแจกชื่อแบบอักษรที่มีในเครื่องได้ รายการจะจัดกลุ่มตามสิ่งที่มีจริง แต่ถ้าแจกชื่อไม่ได้ รายการจะแสดงรายชื่อผู้สมัครทั้งหมด

แบบอักษรทุกตัวในรายการ ถ้าไม่ได้ติดตั้งอยู่ในคอมพิวเตอร์เครื่องนี้ ก็เป็นแบบอักษรที่มาพร้อมกับแอป ไม่มีการดาวน์โหลดอะไรทั้งสิ้น

## การติดตั้งไฟล์แบบอักษร (Slides)

- ที่ด้านล่างสุดของรายการแบบอักษรใน Slides คำสั่ง **ติดตั้งไฟล์แบบอักษร…** ใช้เพิ่มไฟล์แบบอักษรที่คุณมีอยู่แล้ว ได้แก่ .ttf, .otf, .ttc หรือ .otc
- ไฟล์จะถูกคัดลอกไปไว้ในโฟลเดอร์แบบอักษรของแอปเอง ใช้ได้เฉพาะในแอปนี้ ไม่มีอะไรถูกติดตั้งลงในระบบ งานนำเสนอที่เปิดอยู่จะถูกจัดวางใหม่ด้วยแบบอักษรใหม่
- ถ้าไฟล์เหล่านั้นมีตระกูลแบบอักษรเพียงตระกูลเดียว ตระกูลนั้นจะถูกนำไปใช้กับสิ่งที่คุณเลือกอยู่ทันที
- แบบอักษรที่ติดตั้งด้วยวิธีนี้จะไม่ปรากฏในรายการ หากต้องการใช้ภายหลัง ให้พิมพ์ชื่อลงในช่องแบบอักษร
- ติดตั้งหลายน้ำหนักของตระกูลเดียวกันไว้ด้วยกันได้
- แอปไม่มีคำสั่งสำหรับลบแบบอักษรที่ติดตั้งด้วยวิธีนี้

## แบบอักษรที่เอกสารต้องใช้แต่คุณไม่มี

- เอกสารที่ใช้แบบอักษรที่ไม่ได้ติดตั้งไว้ จะแสดงด้วยแบบอักษรทดแทน

## การจัดหน้าเอกสารภาษาจีน ญี่ปุ่น เกาหลี

- แบบอักษรจีน ญี่ปุ่น เกาหลี ใน Docs รองรับการบีบอัดเครื่องหมายวรรคตอนและกฎห้ามขึ้นบรรทัดและห้ามลงท้ายบรรทัดที่สอดคล้องกับ Word (ดูบทของ Docs)
