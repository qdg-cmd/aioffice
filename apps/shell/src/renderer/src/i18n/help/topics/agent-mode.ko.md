# 에이전트 모드

에이전트는 고른 폴더 하나를 프로젝트로 삼아, 이 PC의 Claude Code나 Codex를 그 폴더에서 실행합니다. AI가 폴더의 자료를 직접 읽고, 새 파일을 만들고, 스킬과 스크립트를 쓰고, GenOffice에 열려 있는 문서를 고칩니다. 자료가 많은 일을 맡길 때 씁니다.

## 준비물

- **설정 ▸ AI**에서 연결된 Claude 구독 또는 ChatGPT 구독. 연결 방법은 "구독 연결" 주제에 있습니다.
- 자료를 모아 둔 폴더. 드라이브 전체, 사용자 폴더 전체, 로그인 정보나 앱 데이터가 든 폴더는 고를 수 없습니다.

## 시작하기

1. 홈 왼쪽 목록에서 **에이전트**를 누릅니다. 에이전트 창이 따로 열립니다.
2. **폴더 고르기…**로 프로젝트 폴더를 고릅니다. 최근에 쓴 폴더는 **최근 폴더**에서 다시 고를 수 있습니다.
3. **프로그램**에서 Claude Code나 Codex를 고릅니다. 연결되지 않은 프로그램은 고를 수 없습니다.
4. **언제 물을까요**에서 허락 방식을 고릅니다(아래 표).
5. 처음 한 번은 **시작하기 전에** 안내를 읽고 **이해했습니다**를 누릅니다.
6. **시작**을 누른 뒤, 할 일을 적고 **보내기**를 누릅니다.

창 하나가 세션 하나입니다. 창을 닫거나 **멈추기**를 누르면 세션이 끝나고, GenOffice가 띄운 프로그램도 함께 꺼집니다. 30분 동안 아무것도 보내지 않아도 끝납니다.

## 허락 방식

| 방식                               | 바로 하는 일                                       | 먼저 묻는 일                                |
| ---------------------------------- | -------------------------------------------------- | ------------------------------------------- |
| **명령 실행마다 묻기**(기본)       | 프로젝트 폴더의 파일 읽기와 쓰기, 열린 문서 고치기 | 명령·스크립트 실행, 프로젝트 폴더 밖 읽기   |
| **파일 쓰기와 명령 실행마다 묻기** | 프로젝트 폴더의 파일 읽기, 열린 문서 고치기        | 파일 쓰기, 명령·스크립트 실행, 폴더 밖 읽기 |
| **이 프로젝트는 믿고 맡기기**      | 거의 모든 일                                       | 프로젝트 폴더 밖 읽기                       |

물을 때는 창에 무엇을 하려는지(명령 전체, 파일 경로)가 보입니다. **허락**이나 **거절**을 누릅니다.

어느 방식이든 다음은 하지 않습니다.

- GenOffice 탭에 열린 문서의 파일을 직접 덮어쓰기. 열린 문서는 앱을 거쳐 고치므로 편집기에 바로 보이고, 편집기의 되돌리기로 되돌릴 수 있습니다.
- 프로젝트 폴더 밖에 쓰기.
- Claude·Codex의 로그인 정보나 GenOffice의 데이터 폴더에 닿기.

## Claude Code와 Codex의 차이

- **Codex**는 명령을 자체 격리 공간에서 실행합니다. 허락한 명령도 같습니다. 프로젝트 폴더에만 쓸 수 있고, 인터넷은 켜 두지 않으면 막히고, 프로젝트 밖의 개인 파일은 읽지 못합니다. 시작할 때 이 PC에서 격리가 제대로 되는지 먼저 확인하고, 안 되면 시작하지 않습니다.
- **Claude Code**는 Windows에서 명령을 격리하지 못합니다. 허락한 명령은 PC 전체와 인터넷에 닿을 수 있습니다. 그래서 **이 프로젝트는 믿고 맡기기**에서는 Claude Code의 자체 검사 모델이 행동마다 대신 확인합니다.

남에게 받은 문서에는 AI에게 엉뚱한 일을 시키는 숨은 지시가 들어 있을 수 있습니다. 모르는 자료가 든 폴더에서는 묻는 방식을 쓰세요.

## 웹 검색과 인터넷

- **Claude Code**는 웹 검색과 웹 페이지 읽기를 쓸 수 있고, 쓰기 전에 묻습니다. 검색은 처음 쓸 때, 웹 페이지 읽기는 사이트마다 묻습니다. 묻는 창에서 **이번 세션 동안 검색 허락**이나 **이번 세션 동안 이 사이트 허락**을 누르면 그 세션 동안은 다시 묻지 않습니다. **이 프로젝트는 믿고 맡기기**에서는 Claude Code의 자체 검사가 판단합니다.
- **Codex**를 고르면 시작 화면에 두 설정이 더 보입니다.

| 설정                   | 고를 수 있는 것             | 처음 값     |
| ---------------------- | --------------------------- | ----------- |
| **웹 검색**            | 저장된 결과 / 실시간 / 끄기 | 저장된 결과 |
| **명령의 인터넷 접속** | 끔 / 켬                     | 끔          |

- 저장된 결과는 미리 모아 둔 웹 자료에서 찾고, 실시간은 지금의 웹을 검색합니다.
- 두 설정은 프로젝트 폴더마다 따로 기억합니다. 처음 쓰는 폴더는 처음 값으로 시작합니다.
- 명령의 인터넷 접속을 켜면 Codex가 실행하는 명령이 인터넷에 닿습니다. **이 프로젝트는 믿고 맡기기**에서는 묻지 않고 닿고, 받은 문서에 숨은 지시가 자료를 밖으로 보내게 할 수 있습니다. 켤 때 이 경고가 보입니다. 꼭 필요할 때만 켜세요. 기본 스킬 "스킬 찾기"는 이 설정이 켜져 있어야 동작합니다.

## 프로젝트 지침과 스킬

- 폴더에 `CLAUDE.md`나 `AGENTS.md`가 있으면 그 내용을 지시로 함께 줍니다. 글투, 용어, 만들 문서의 형식처럼 매번 지킬 것을 적어 두면 됩니다.
- 에이전트 창은 **설정 ▸ 스킬**에서 켠 스킬을 씁니다. Claude Code와 Codex가 같은 목록을 받습니다. 스킬에 대한 자세한 내용은 [스킬](help://skills)에 있습니다.
- 프로젝트 폴더의 `.claude/skills`와 `.agents/skills`에 든 스킬은 따로 켜지 않아도 그 세션에서 쓰입니다.
- 입력칸에서 `/`나 `$`로 스킬을 고르면, 그 스킬을 읽고 따르라는 지시가 요청 앞에 붙습니다.
- 스킬 목록은 세션을 시작할 때 정해집니다. 세션 도중에 스킬을 켜고 끄면 "바뀐 스킬은 다음 세션부터 적용됩니다"가 보입니다.
- 에이전트가 스킬을 만들면 창에 스킬 카드가 뜨고, 쓸 만한 스킬을 찾으면 설치 미리보기가 뜹니다. 둘 다 사람이 **저장**이나 **설치**를 눌러야 반영되고, 설치한 스킬은 다음 세션부터 쓰입니다.
- 스킬의 스크립트가 쓰는 프로그램(Python 등)은 이 PC에 설치되어 있어야 합니다.
- 이전 버전에서 에이전트를 쓰던 분이 에이전트 창을 처음 열면 "스킬은 이제 설정 → 스킬에서 켜고 끕니다. Claude·Codex 스킬 폴더의 스킬은 꺼진 채로 시작합니다"라는 안내가 한 번 뜹니다. **설정 열기**를 누르면 바로 그 화면으로 갑니다.

## 만든 파일과 열린 문서

- 에이전트가 만든 새 파일은 프로젝트 폴더에 저장됩니다. 진행 기록의 그 줄에서 **열기**를 누르면 GenOffice 탭으로 열립니다.
- 열린 문서를 고치게 하려면 먼저 GenOffice에서 그 문서를 열어 두고, 요청에 문서 이름을 적습니다.
- 세션 도중에 연 문서도 다음 메시지부터 고칠 수 있습니다.

## 개인정보와 사용량

- AI에게서 가린 부분은 GenOffice에 열린 문서를 앱이 읽어 줄 때만 가려집니다. 에이전트가 폴더에서 직접 읽는 파일은 그대로 보내집니다.
- 웹 검색어와 읽은 웹 페이지 주소는 그 프로그램의 회사와 해당 사이트로 갑니다. Codex의 명령의 인터넷 접속을 켜면 명령이 연결하는 곳으로 자료가 나갈 수 있습니다.
- 에이전트는 여러 단계로 일하므로 AI 창보다 구독 한도를 많이 씁니다. 한도를 다 쓰면 그 요청은 실패로 끝나고, 다른 AI나 요금이 나가는 연결로 넘어가지 않습니다.

## 문제가 생기면

| 창에 보이는 말                                   | 할 일                                                     |
| ------------------------------------------------ | --------------------------------------------------------- |
| **연결되지 않았습니다**                          | **설정 ▸ AI**에서 그 프로그램에 로그인합니다.             |
| **이 폴더는 쓸 수 없습니다**                     | 작업 자료만 든 폴더를 고릅니다.                           |
| **격리 공간을 열 수 없어서 시작하지 않았습니다** | Windows를 최신으로 업데이트하거나 Claude Code를 고릅니다. |
| **구독 한도를 다 썼습니다**                      | 한도가 풀린 뒤 다시 보냅니다.                             |
| **에이전트 모드를 쓰기에는 오래되었습니다**      | 그 프로그램을 업데이트한 뒤 **새로 시작**을 누릅니다.     |
