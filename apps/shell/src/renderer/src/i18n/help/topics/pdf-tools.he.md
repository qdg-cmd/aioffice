# כלי PDF

חלון למשימות יומיומיות ב-PDF שמתחיל מהמשימה. התוצאה נשמרת תמיד כקובץ חדש והמקור לא משתנה. הכלים בחלון הזה פועלים רק במחשב הזה ולא משתמשים בבינה מלאכותית.

## איך זה עובד

1. במסך הבית, לחצו על הכרטיס **כלי PDF**. ייפתח חלון נפרד.
2. בחרו משימה, את הקבצים שהיא צריכה ואת האפשרויות, ולחצו על **שמירה כקובץ חדש**.
3. אחרי השמירה, **פתיחה בכרטיסייה** מציג את התוצאה מיד, ו-**הצגה בתיקייה** פותח את התיקייה שלה.

| קבוצה        | כלים                                                                                     |

| הכנה להדפסה  | הכנה להדפסה דו-צדדית, איחוד עמודים, גודל עמוד, פיצול עמודים                              |

| גודל ואבטחה  | הקטנת הגודל, הוספת סיסמה, הסרת סיסמה, תיקון קובץ                                         |

הכרטיסים ב-**בעורך ה-PDF** פותחים את קובץ ה-PDF שנבחר בכרטיסייה של העורך. שם בחרו את הפקודה ברצועת הכלים.

## כדאי לדעת

- אי אפשר לשמור על קובץ מקור או על קובץ שפתוח עם שינויים שלא נשמרו.
- אפשר להשתמש בקובץ PDF המוגן בסיסמה בכלים האחרים רק אחרי **הסרת סיסמה**. אי אפשר לפתוח קובץ שאת הסיסמה שלו אתם לא יודעים.
- **תיקון קובץ** משחזר רק את החלקים שעדיין אפשר לקרוא. פתחו את הקובץ החדש ובדקו שלא חסרים עמודים.
- **הסרת עמודים ריקים** רק מציג מועמדים. מוסרים רק העמודים שבחרתם, ועמוד שיש בו ולו תו אחד אף פעם אינו מועמד.
- **הסרת הערות** משאיר שדות טופס ומסיר קישורים רק אם סימנתם אותם. תוכן ההערות שהוסרו לא נשאר בקובץ החדש.
- **שמירה כטקסט** קורא רק את שכבת הטקסט. עמודים שהטקסט בהם הוא תמונה, כמו עמודים סרוקים, יהיו ריקים.
