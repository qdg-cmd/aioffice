# エージェントモード

エージェントは、選んだフォルダー 1 つをプロジェクトとして、この PC の Claude Code または Codex をそのフォルダーで実行します。AI がフォルダー内の資料を自分で読み、新しいファイルを作り、スキルやスクリプトを使い、GenOffice で開いている文書を編集します。たくさんの資料を使う作業を任せたいときに使います。

## 用意するもの

- **設定 ▸ AI** で接続済みの Claude のサブスクリプションまたは ChatGPT のサブスクリプション。接続方法は「サブスクリプションの接続」のトピックで説明しています。
- 資料をまとめたフォルダー。ドライブ全体、ホームフォルダー全体、サインイン情報やアプリのデータが入ったフォルダーは選べません。

## セッションを始める

1. ホームの左側の一覧で **エージェント** を押します。エージェントのウィンドウが別に開きます。
2. **フォルダーを選ぶ…** を押して、プロジェクトのフォルダーを選びます。最近使ったフォルダーは **最近のフォルダー** に並びます。
3. **プログラム** で Claude Code か Codex を選びます。接続されていないプログラムは選べません。
4. **確認するタイミング** で、エージェントが許可を求める方法を選びます（下の表）。
5. 初めてのときは **始める前に** の説明を読み、**理解しました** を押します。
6. **開始** を押し、してほしいことを書いて **送信** を押します。

ウィンドウ 1 つが 1 つのセッションです。ウィンドウを閉じるか **停止** を押すとセッションが終わり、GenOffice がそのために起動したプログラムも一緒に終了します。30 分間何も送らなかった場合も、セッションは終わります。

## エージェントの確認のしかた

| 選択肢                                 | そのまま進めること                                                 | 先に確認すること                                                       |
| -------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| **コマンドの実行ごとに確認**（既定）   | プロジェクトフォルダー内のファイルの読み書き、開いている文書の編集 | コマンドやスクリプトの実行、プロジェクトフォルダー外の読み取り         |
| **書き込みとコマンドの実行ごとに確認** | プロジェクトフォルダー内のファイルの読み取り、開いている文書の編集 | ファイルの書き込み、コマンドやスクリプトの実行、フォルダー外の読み取り |
| **このプロジェクトを信頼する**         | ほぼすべて                                                         | プロジェクトフォルダー外の読み取り                                     |

エージェントが確認を求めると、ウィンドウに何をしようとしているか（コマンド全体、ファイルのパス）が表示されます。**許可** か **拒否** を押します。

どれを選んでも、エージェントは次のことはしません。

- GenOffice のタブで開いている文書のファイルを上書きすること。開いている文書はアプリを通して編集されるので、変更はすぐ編集画面に表示され、編集画面の元に戻す操作で取り消せます。
- プロジェクトフォルダーの外に書き込むこと。
- Claude や Codex のサインイン情報、GenOffice のデータフォルダーに触れること。

## Claude Code と Codex の違い

- **Codex** は、許可したものも含め、コマンドを独自の隔離された環境で実行します。書き込めるのはプロジェクトフォルダーだけで、オンにしない限りインターネットは遮断され、プロジェクト外の個人のファイルは読めません。セッションを始めるとき、GenOffice はまずこの PC で隔離が働くかを確認し、働かなければ開始しません。
- **Claude Code** は、Windows ではコマンドを隔離できません。許可したコマンドは PC 全体とインターネットに届きます。そのため **このプロジェクトを信頼する** では、あなたの代わりに Claude Code 自身のチェック機能が操作ごとに確認します。

人から受け取った文書には、AI に別のことをさせる隠れた指示が含まれていることがあります。中身をよく知らない資料のフォルダーでは、確認する方式のどれかを使ってください。

## ウェブ検索とインターネット

- **Claude Code** はウェブを検索し、ウェブページを読むことができますが、その前に確認を求めます。最初に検索するときと、ページを読むサイトごとに確認します。確認の画面で **このセッション中は検索を許可** または **このセッション中はこのサイトを許可** を選ぶと、そのセッションの残りの間はもう確認しません。**このプロジェクトを信頼する** では、Claude Code 自身のチェック機能が判断します。
- **Codex** を選ぶと、開始画面に設定が 2 つ増えます。

| 設定                             | 選択肢                               | 最初の値       |
| -------------------------------- | ------------------------------------ | -------------- |
| **ウェブ検索**                   | 保存済みの結果 / リアルタイム / オフ | 保存済みの結果 |
| **コマンドのインターネット接続** | オフ / オン                          | オフ           |

- 保存済みの結果は事前に集めたウェブの内容から探し、リアルタイムは今のウェブを検索します。
- どちらの設定もプロジェクトフォルダーごとに記憶されます。初めて使うフォルダーは上の表の値で始まります。
- コマンドのインターネット接続をオンにすると、Codex が実行するコマンドがインターネットに届くようになります。**このプロジェクトを信頼する** では確認なしで接続するため、受け取った文書の隠れた指示によって、あなたのデータが外に送られるおそれがあります。オンにするときにはこの警告が表示されます。必要なときだけオンにしてください。標準スキル「スキルを探す」は、この設定がオンのときだけ使えます。

## プロジェクトのメモとスキル

- フォルダーに `CLAUDE.md` や `AGENTS.md` があれば、その内容が指示としてエージェントに渡されます。文体、用語、作る文書の形式など、毎回守ってほしいことを書いておきます。
- エージェントのウィンドウでは、**設定 ▸ スキル** でオンにしたスキルが使われます。Claude Code にも Codex にも同じ一覧が渡されます。スキルについて詳しくは [スキル](help://skills) をご覧ください。
- プロジェクトフォルダーの `.claude/skills` と `.agents/skills` にあるスキルは、オンにしなくてもそのセッションで使われます。
- 入力欄で `/` や `$` を使ってスキルを選ぶと、そのスキルを読んで従うようにという指示が依頼の前に付きます。
- スキルの一覧はセッションを始めた時点で決まります。セッションの途中でスキルをオン・オフすると、「変更したスキルは次のセッションから反映されます」と表示されます。
- エージェントがスキルを作るとウィンドウにスキルのカードが、インストールする価値のあるスキルを見つけるとインストールのプレビューが表示されます。**保存** か **インストール** を押すまで、何も保存もインストールもされません。インストールしたスキルは次のセッションから使えます。
- スキルのスクリプトが使うプログラム（Python など）は、この PC にインストールされている必要があります。
- 以前のバージョンでエージェントを使っていた場合、初めてエージェントのウィンドウを開いたときに 1 回だけ次のお知らせが出ます。「スキルは 設定 → スキル でオン・オフするようになりました。Claude と Codex のスキルフォルダーのスキルはオフの状態で始まります。」**設定を開く** を押すと、そこへ直接移動します。

## 新しいファイルと開いている文書

- エージェントが作った新しいファイルは、プロジェクトフォルダーに保存されます。進行記録のその行で **開く** を押すと、GenOffice のタブで開きます。
- 開いている文書を編集させるには、先に GenOffice でその文書を開き、依頼の中で文書の名前を書きます。
- セッションの途中で開いた文書も、次のメッセージから編集できます。

## プライバシーと使用量

- AI から隠した内容が隠れたままなのは、GenOffice で開いている文書をアプリがエージェントのために読み取るときだけです。エージェントがフォルダーから直接読むファイルは、そのまま送られます。
- ウェブ検索の語句と、読んだページのアドレスは、そのプログラムの会社とそれらのサイトに送られます。Codex のコマンドのインターネット接続をオンにしていると、データはコマンドが接続する先ならどこへでも送られる可能性があります。
- エージェントは何段階にも分けて作業するため、AI パネルよりも多くサブスクリプションの上限を使います。上限に達するとその依頼は失敗します。エージェントが別の AI や料金のかかる接続に切り替えることはありません。

## 困ったとき

| ウィンドウの表示                                                     | すること                                                        |
| -------------------------------------------------------------------- | --------------------------------------------------------------- |
| **接続されていません**                                               | **設定 ▸ AI** で、そのプログラムにサインインします。            |
| **このフォルダーは使えません**                                       | 作業用の資料だけが入ったフォルダーを選びます。                  |
| **このPCでは、Codex がコマンドを閉じ込めるサンドボックスを開けない** | Windows を更新するか、Claude Code を選びます。                  |
| **プランの上限に達しました**                                         | 上限がリセットされてから、もう一度送ります。                    |
| **プログラムが古いため、エージェントモードを使えません**             | そのプログラムを更新してから、**新しいセッション** を押します。 |
