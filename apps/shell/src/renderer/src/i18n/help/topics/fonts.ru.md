# Шрифты: системные шрифты и установка файлов шрифтов

## Списки шрифтов

Управление шрифтом находится на вкладке Главная каждого редактора.

Выбор шрифта в каждом редакторе объединяет: установленные локально шрифты и обычные для платформы кандидаты (типичные семейства Windows и macOS, западные и CJK, включая локализованные имена, которые CJK-шрифты сообщают в своих системах). Когда система умеет перечислить локальные шрифты, список группируется по тому, что действительно есть; иначе он сводится к полному списку кандидатов.

Каждый шрифт в списке либо установлен на этом компьютере, либо поставляется с приложением. Ничего не скачивается.

## Установка файла шрифта (Slides)

- Внизу списка шрифтов в Slides пункт **Установить файл шрифта…** добавляет файлы шрифтов, которые у вас уже есть: .ttf, .otf, .ttc или .otc.
- Файлы копируются в собственную папку шрифтов приложения. Они работают только в этом приложении; в систему ничего не устанавливается. Открытые презентации заново верстаются с новым шрифтом.
- Если в файлах одно семейство шрифтов, оно сразу применяется к тому, что у вас выделено.
- Установленный так шрифт не появляется в списке. Чтобы воспользоваться им позже, введите его название в поле шрифта.
- Несколько начертаний одного семейства можно установить рядом.
- В приложении нет команды для удаления шрифта, установленного таким способом.

## Шрифты, которые нужны документу, но которых у вас нет

- Документ, в котором используется неустановленный шрифт, показывается с заменяющим шрифтом.

## Типографика CJK

- CJK-шрифты в Docs получают сжатие знаков препинания и правила переноса кинсоку, согласованные с Word (см. главу про Docs).
