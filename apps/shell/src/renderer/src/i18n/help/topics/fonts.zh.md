# 字体：系统字体与安装字体文件

## 字体列表

字体控件在各编辑器功能区的「开始」页签。

各编辑器的字体选择器合并显示：本机已安装字体 + 平台常见候选（Windows 与 macOS 的常见中西文家族都认得，包括中日韩字体在各自系统上的本地化名字）。系统能枚举本地字体时按实际结果分组；不能枚举时退化为完整候选列表。

列表里的每个字体，要么已安装在这台电脑上，要么随应用附带。不会下载任何东西。

## 安装字体文件（Slides）

- 在 Slides 字体列表的底部，**安装字体文件…** 可以添加你手头已有的字体文件：.ttf、.otf、.ttc 或 .otc。
- 这些文件会被复制到应用自己的字体文件夹里。它们只在本应用中可用，不会安装到系统。已打开的演示文稿会用新字体重新排版。
- 如果这些文件里只有一个字体家族，它会立即应用到你当前选中的内容上。
- 用这种方式安装的字体不会出现在列表里。以后要用，请在字体框里输入它的名字。
- 同一家族的多个字重可以同时安装。
- 应用里没有删除这类字体的命令。

## 文档需要但你没有的字体

- 文档用到未安装的字体时，会用替代字体显示。

## 中文排版

- 中文字体在 Docs 中支持标点压缩、避头尾等 Word 对齐的排版规则（详见 Docs 章）。
