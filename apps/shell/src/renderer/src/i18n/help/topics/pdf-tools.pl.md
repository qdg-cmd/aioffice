# Narzędzia PDF

Okno do codziennych zadań z PDF, które zaczyna się od zadania. Wynik zawsze jest zapisywany jako nowy plik, a oryginał się nie zmienia. Narzędzia w tym oknie działają tylko na tym komputerze i nie używają AI.

## Jak to działa

1. Na ekranie głównym kliknij kartę **Narzędzia PDF**. Otworzy się osobne okno.
2. Wybierz zadanie, potrzebne pliki i opcje, a potem kliknij **Zapisz jako nowy plik**.
3. Po zapisaniu **Otwórz na karcie** od razu pokazuje wynik, a **Pokaż w folderze** otwiera jego folder.

## Narzędzia

| Grupa                    | Narzędzia                                                                                                    |
| ------------------------ | ------------------------------------------------------------------------------------------------------------ |
| Porządkowanie stron      | Scal PDF, Podziel PDF, Wyodrębnij strony jako PDF, Odwróć kolejność, Obróć wszystkie, Usuń puste strony      |
| Przygotowanie do druku   | Przygotuj do druku dwustronnego, Scal strony, Rozmiar strony, Podziel strony                                 |
| Ozdabianie               | Dodaj tło                                                                                                    |
| Porządkowanie            | Usuń adnotacje                                                                                               |
| Konwertuj                | Obrazy do PDF, Zapisz jako tekst                                                                             |
| Rozmiar i bezpieczeństwo | Zmniejsz rozmiar, Dodaj hasło, Usuń hasło, Napraw plik                                                       |
| W edytorze PDF           | Znak wodny i nagłówek/stopka, Przytnij strony, Eksportuj obrazy, Konwertuj PDF, Edycja, podpis, zaczernienie |

Karty w grupie **W edytorze PDF** otwierają wybrany PDF na karcie edytora. Tam wybierz polecenie na wstążce.

## Warto wiedzieć

- Nie można zapisać na pliku źródłowym ani na pliku otwartym z niezapisanymi zmianami.
- PDF chroniony hasłem działa w pozostałych narzędziach dopiero po użyciu **Usuń hasło**. Pliku, którego hasła nie znasz, nie da się otworzyć.
- **Napraw plik** odzyskuje tylko te części, które da się jeszcze odczytać. Otwórz nowy plik i sprawdź, czy nie brakuje żadnej strony.
- **Usuń puste strony** tylko pokazuje kandydatów. Usuwane są tylko wybrane strony, a strona z choćby jednym znakiem nigdy nie jest kandydatem.
- **Usuń adnotacje** zachowuje pola formularza i usuwa łącza tylko po ich zaznaczeniu. Treść usuniętych adnotacji nie zostaje w nowym pliku.
- **Zapisz jako tekst** czyta tylko warstwę tekstu. Strony, na których tekst jest obrazem, np. zeskanowane, będą puste.

## Przydaje się, gdy

| Sytuacja                                                                                | Narzędzia                                     |
| --------------------------------------------------------------------------------------- | --------------------------------------------- |
| Drukujesz dwustronnie kilka dokumentów naraz i każdy ma zaczynać się na przodzie kartki | Przygotuj do druku dwustronnego → Scal strony |
| Zeskanowany dokument ma odwróconą kolejność lub leżące strony                           | Odwróć kolejność, Obróć wszystkie             |
| Między stronami zeskanowanego pliku znalazły się puste strony                           | Usuń puste strony                             |
| Chcesz nałożyć papier firmowy firmy lub instytucji na każdą stronę                      | Dodaj tło                                     |
| Porządkujesz komentarze przed wysłaniem sprawdzonego dokumentu                          | Usuń adnotacje                                |
| Oddajesz kilka zdjęć jako jeden PDF                                                     | Obrazy do PDF                                 |
| Chcesz użyć tekstu z PDF w innym dokumencie                                             | Zapisz jako tekst                             |
| PDF jest za duży, by dołączyć go do e-maila                                             | Zmniejsz rozmiar                              |
| PDF, którego pobieranie się przerwało, nie otwiera się                                  | Napraw plik                                   |
