# PDF-hulpmiddelen

Een venster voor alledaagse pdf-taken dat bij de taak begint. Het resultaat wordt altijd als nieuw bestand opgeslagen en het origineel blijft ongewijzigd. De hulpmiddelen in dit venster werken alleen op deze pc en gebruiken geen AI.

## Zo werkt het

1. Klik op Start op de kaart **PDF-hulpmiddelen**. Er opent een apart venster.
2. Kies een taak, de bestanden die ze nodig heeft en de opties, en klik op **Opslaan als nieuw bestand**.
3. Na het opslaan toont **Openen in een tabblad** het resultaat meteen en opent **Tonen in map** de map ervan.

## De hulpmiddelen

| Groep                  | Hulpmiddelen                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| Pagina’s ordenen       | PDF's samenvoegen, PDF splitsen, Pagina's extraheren als PDF, Volgorde omkeren, Alles roteren, Lege pagina’s verwijderen       |
| Afdrukken voorbereiden | Voorbereiden op dubbelzijdig, Pagina's combineren, Paginaformaat, Pagina's splitsen                                            |
| Opmaken                | Achtergrond toevoegen                                                                                                          |
| Opschonen              | Aantekeningen verwijderen                                                                                                      |
| Converteren            | Afbeeldingen naar pdf, Opslaan als tekst                                                                                       |
| Grootte en beveiliging | Kleiner maken, Wachtwoord toevoegen, Wachtwoord verwijderen, Bestand herstellen                                                |
| In de PDF-editor       | Watermerk & kop-/voettekst, Pagina's bijsnijden, Afbeeldingen exporteren, PDF converteren, Bewerken, ondertekenen, zwart maken |

De kaarten onder **In de PDF-editor** openen de gekozen pdf in een editortabblad. Kies daar de opdracht op het lint.

## Goed om te weten

- U kunt niet opslaan over een bronbestand of over een bestand dat geopend is met niet-opgeslagen wijzigingen.
- Een met een wachtwoord beveiligde pdf werkt pas in de andere hulpmiddelen na **Wachtwoord verwijderen**. Een bestand waarvan u het wachtwoord niet kent, kan niet worden geopend.
- **Bestand herstellen** haalt alleen de delen terug die nog leesbaar zijn. Open het nieuwe bestand en controleer of er geen pagina ontbreekt.
- **Lege pagina’s verwijderen** toont alleen kandidaten. Alleen de gekozen pagina’s worden verwijderd, en een pagina met ook maar één teken is nooit een kandidaat.
- **Aantekeningen verwijderen** laat formuliervelden staan en verwijdert koppelingen alleen als u ze aanvinkt. De inhoud van verwijderde aantekeningen blijft niet in het nieuwe bestand.
- **Opslaan als tekst** leest alleen de tekstlaag. Pagina’s waarvan de tekst een afbeelding is, zoals gescande pagina’s, blijven leeg.

## Handig voor

| Situatie                                                                           | Hulpmiddelen                                       |
| ---------------------------------------------------------------------------------- | -------------------------------------------------- |
| Meerdere documenten tegelijk dubbelzijdig afdrukken, elk beginnend op een voorkant | Voorbereiden op dubbelzijdig → Pagina's combineren |
| Een gescand document staat in omgekeerde volgorde of heeft liggende pagina’s       | Volgorde omkeren, Alles roteren                    |
| Tussen de pagina’s van een gescande stapel zitten lege pagina’s                    | Lege pagina’s verwijderen                          |
| Het briefpapier van een bedrijf of organisatie op elke pagina zetten               | Achtergrond toevoegen                              |
| Opmerkingen opruimen voordat u een nagekeken document verstuurt                    | Aantekeningen verwijderen                          |
| Meerdere foto’s als één pdf inleveren                                              | Afbeeldingen naar pdf                              |
| De tekst van een pdf in een ander document gebruiken                               | Opslaan als tekst                                  |
| Een pdf is te groot om bij een e-mail te voegen                                    | Kleiner maken                                      |
| Een pdf waarvan het downloaden halverwege stopte, opent niet                       | Bestand herstellen                                 |
