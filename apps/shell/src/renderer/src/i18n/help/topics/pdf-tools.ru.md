# Инструменты PDF

Окно для повседневных задач с PDF, где всё начинается с выбора задачи. Результат всегда сохраняется в новый файл, а оригинал не меняется. Инструменты этого окна работают только на этом компьютере и не используют ИИ.

## Как это работает

1. На главном экране нажмите карточку **Инструменты PDF**. Откроется отдельное окно.
2. Выберите задачу, нужные файлы и параметры, затем нажмите **Сохранить как новый файл**.
3. После сохранения **Открыть во вкладке** сразу покажет результат, а **Показать в папке** откроет его папку.

## Инструменты

| Группа               | Инструменты                                                                                                      |
| -------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Упорядочить страницы | Объединить PDF, Разделить PDF, Извлечь страницы в PDF, Обратный порядок, Повернуть все, Удалить пустые страницы  |
| Подготовка к печати  | Подготовить к двусторонней печати, Объединить страницы, Размер страницы, Разделить страницы                      |
| Оформление           | Добавить фон                                                                                                     |
| Очистка              | Удалить аннотации                                                                                                |
| Преобразование       | Изображения в PDF, Сохранить как текст                                                                           |
| Размер и защита      | Уменьшить размер, Поставить пароль, Снять пароль, Восстановить файл                                              |
| В редакторе PDF      | Водяной знак и колонтитулы, Обрезать страницы, Экспорт изображений, Конвертировать PDF, Правка, подпись, скрытие |

Карточки группы **В редакторе PDF** открывают выбранный PDF во вкладке редактора. Выберите там команду на ленте.

## Полезно знать

- Нельзя сохранить поверх исходного файла или поверх файла, открытого с несохранёнными изменениями.
- PDF с паролем можно использовать в других инструментах только после инструмента **Снять пароль**. Файл, пароль которого вы не знаете, открыть нельзя.
- **Восстановить файл** возвращает только те части, которые ещё читаются. Откройте новый файл и проверьте, что ни одна страница не пропала.
- **Удалить пустые страницы** только показывает кандидатов. Удаляются лишь выбранные страницы, а страница хотя бы с одним символом никогда не становится кандидатом.
- **Удалить аннотации** сохраняет поля форм и удаляет ссылки, только если их отметить. Содержимое удалённых аннотаций не остаётся в новом файле.
- **Сохранить как текст** читает только текстовый слой. Страницы, где текст — изображение (например, отсканированные), будут пустыми.

## Пригодится, когда

| Ситуация                                                                                          | Инструменты                                             |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| Нужно напечатать несколько документов с двух сторон, и каждый должен начинаться с лицевой стороны | Подготовить к двусторонней печати → Объединить страницы |
| Отсканированный документ оказался в обратном порядке или со страницами на боку                    | Обратный порядок, Повернуть все                         |
| Между страницами отсканированной пачки попались пустые страницы                                   | Удалить пустые страницы                                 |
| Нужно нанести фирменный бланк компании или организации на каждую страницу                         | Добавить фон                                            |
| Перед отправкой проверенного документа нужно убрать комментарии                                   | Удалить аннотации                                       |
| Нужно сдать несколько фотографий одним PDF                                                        | Изображения в PDF                                       |
| Нужно использовать текст из PDF в другом документе                                                | Сохранить как текст                                     |
| PDF слишком большой, чтобы приложить его к письму                                                 | Уменьшить размер                                        |
| PDF, загрузка которого оборвалась, не открывается                                                 | Восстановить файл                                       |
