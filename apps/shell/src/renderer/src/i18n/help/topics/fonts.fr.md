# Polices : polices système et installation de fichiers de police

## Les listes de polices

Les contrôles de police se trouvent sur l’onglet Accueil de chaque éditeur.

Le sélecteur de polices de chaque éditeur réunit : les polices installées localement + les candidates habituelles de la plateforme (les familles courantes de Windows et de macOS, latines et est-asiatiques, y compris les noms localisés que les polices est-asiatiques signalent sur leur système d’origine). Lorsque le système sait énumérer les polices locales, la liste est regroupée selon ce qui existe réellement ; sinon elle se replie sur la liste complète des candidates.

Chaque police de la liste est soit installée sur ce PC, soit livrée avec l’application. Rien n’est téléchargé.

## Installer un fichier de police (Slides)

- En bas de la liste des polices de Slides, **Installer un fichier de police…** ajoute des fichiers de police que vous possédez déjà : .ttf, .otf, .ttc ou .otc.
- Les fichiers sont copiés dans le dossier de polices propre à l’application. Ils ne fonctionnent que dans cette application ; rien n’est installé dans le système. Les présentations ouvertes sont remises en page avec la nouvelle police.
- Lorsque les fichiers contiennent une seule famille de polices, elle est appliquée aussitôt à votre sélection.
- Une police installée de cette façon n’apparaît pas dans la liste. Pour l’utiliser plus tard, saisissez son nom dans la zone de police.
- Plusieurs graisses d’une même famille peuvent être installées côte à côte.
- L’application n’a pas de commande pour retirer une police installée de cette façon.

## Les polices qu’un document demande et que vous n’avez pas

- Un document qui utilise une police non installée s’affiche avec une police de substitution.

## Typographie est-asiatique

- Les polices est-asiatiques dans Docs bénéficient de la compression des signes et des règles de césure alignées sur Word (voir le chapitre Docs).
