# PDF ツール

よく使う PDF の作業を、やりたいことから選んで処理するウィンドウです。結果は必ず新しいファイルとして保存され、元のファイルは変わりません。このウィンドウのツールはこの PC 内だけで処理し、AI は使いません。

## 使い方

1. ホーム画面で **PDF ツール** カードをクリックします。別のウィンドウが開きます。
2. 作業を選び、必要なファイルを選んでオプションを決め、**新しいファイルとして保存** をクリックします。
3. 保存したら **タブで開く** ですぐに結果を確認するか、**フォルダーを開く** でファイルの場所を開きます。

## ツール一覧

| グループ             | ツール                                                                                              |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| ページの整理         | PDF を結合、PDF を分割、ページを PDF として抽出、逆順に並べ替え、すべて回転、白紙ページを探して削除 |
| 印刷の準備           | 両面印刷用にそろえる、ページを集約、ページサイズ、ページを分割                                      |
| 装飾                 | 背景を重ねる                                                                                        |
| 整理                 | 注釈をまとめて削除                                                                                  |
| 変換                 | 画像から PDF を作成、テキストとして保存                                                             |
| サイズとセキュリティ | サイズを小さくする、パスワードを付ける、パスワードを外す、ファイルを修復                            |
| PDF エディターで     | 透かしとヘッダー/フッター、ページをトリミング、画像を書き出す、PDF 変換、編集・署名・墨消し         |

**PDF エディターで** グループのカードは、選んだ PDF をエディターのタブで開きます。リボンでその機能を選んでください。

## 知っておきたいこと

- 元のファイルや、未保存の変更があるまま開いているファイルには保存できません。
- パスワード付きの PDF は、先に**パスワードを外す**で外すとほかのツールで使えます。パスワードがわからないファイルは開けません。
- **ファイルを修復**は読み取れる部分だけを取り戻します。新しいファイルを開き、欠けたページがないか確かめてください。
- **白紙ページを探して削除** は候補を表示するだけです。選んだページだけを削除し、1 文字でも文字があるページは候補に出ません。
- **注釈をまとめて削除** はフォームの入力欄を削除せず、リンクは選んだときだけ削除します。削除した注釈の内容は新しいファイルに残りません。
- **テキストとして保存** は文字のレイヤーだけを読みます。スキャンしたページのように文字が画像になっているページは空になります。

## こんなときに

| 状況                                                         | 使うツール                          |
| ------------------------------------------------------------ | ----------------------------------- |
| 複数の文書を一度に両面印刷し、どの文書も表面から始めたい     | 両面印刷用にそろえる → ページを集約 |
| スキャンした文書の順序が逆になった、またはページが横になった | 逆順に並べ替え、すべて回転          |
| スキャンした束のあいだに白紙ページが混じっている             | 白紙ページを探して削除              |
| 会社や団体のレターヘッドをすべてのページに入れたい           | 背景を重ねる                        |
| 確認が終わった文書を送る前にコメントを整理したい             | 注釈をまとめて削除                  |
| 複数の写真を 1 つの PDF にまとめて提出したい                 | 画像から PDF を作成                 |
| PDF の文章をほかの文書で使いたい                             | テキストとして保存                  |
| メールに添付するには PDF が大きすぎる                        | サイズを小さくする                  |
| ダウンロードが途中で止まった PDF が開けない                  | ファイルを修復                      |
