# Командная строка и агенты

Каждая установка включает команду `ieumoffice`, которая задействует те же движки, что и окно, — те же разборщики, тот же исполнитель записи, тот же рендерер. Файл, сохранённый приложением, и файл, записанный командой, — это один и тот же файл, а проверка, которую проходит панель ИИ, проходит и команда.

```sh
ieumoffice --help          # every command
ieumoffice guide slides    # the op reference, for writing your own
```

`ieumoffice --help` показывает всю поверхность на одном экране: каждая команда со строкой о том, что она делает, а затем глобальные параметры и коды выхода.

## Как получить команду

Команда поставляется внутри приложения. Чтобы звать её по имени, один раз выполните `ieumoffice install-cli`: в Windows она добавляет папку с командой в ваш пользовательский `PATH`, и терминалы, открытые после этого, её находят. Раздел **Настройки ▸ Интеграции** показывает, находит ли уже ваш терминал команду, а если нет — точную строку, которую нужно выполнить.

Агентам для программирования этот шаг не нужен. Приложение записывает расположение команды в `~/.ieumoffice/launcher`, и они находят её там.

## Команды, о которых стоит знать

| Команда           | Что делает                                                                                                                                                                                                                                        |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open`            | Открывает документ в приложении; запускает приложение, если оно не работает.                                                                                                                                                                      |
| `selection`       | Что пользователь выделил в этом файле прямо сейчас, пока приложение запущено, — указатель на «это» / «здесь». Возвращает диапазон блоков, диапазон ячеек листа, элементы слайда или страницу — в зависимости от редактора, в котором открыт файл. |
| `convert`         | Конвертирует между форматами средствами собственных движков приложения.                                                                                                                                                                           |
| `create`          | Создаёт документ из структурированного содержимого.                                                                                                                                                                                               |
| `render`          | По одному PNG на страницу — ровно так, как их раскладывает рендерер.                                                                                                                                                                              |
| `pdf`             | Читает текстовый слой PDF постранично, без процесса приложения.                                                                                                                                                                                   |
| `read-url`        | Читает текст веб-страницы из командной строки — статью, документ или ссылку из навыка; выводит текст и продолжает с `--offset`.                                                                                                                   |
| `info`            | Метаданные и сводка структуры документа.                                                                                                                                                                                                          |
| `search`          | Поиск в вебе или поиск изображений: по умолчанию бесплатный поиск либо поисковый провайдер, чей ключ вы выбрали в приложении.                                                                                                                     |
| `image` / `media` | Создаёт изображение либо описывает файл изображения, видео или аудио и отвечает на вопросы о нём.                                                                                                                                                 |
| `merge`           | Заполняет подстановки `{{key}}` в шаблоне `.docx`, `.pptx` или `.xlsx`.                                                                                                                                                                           |
| `capabilities`    | Сообщает, какие функции ИИ (поиск, генерация изображений, анализ изображений и видео) доступны на этой машине и каким путём.                                                                                                                      |
| `guide`           | Справка по op и руководства по дизайну, сгенерированные из тех же определений, по которым исполнитель проверяет допустимость, — поэтому она не может разойтись с тем, что принимает `apply`. `--json` возвращает её вместе со схемой каждой op.   |
| `install-cli`     | Помещает `ieumoffice` в `PATH`.                                                                                                                                                                                                                   |
| `skill`           | Показывает найденных на этой машине агентов для программирования и ставит или обновляет в них skill GenOffice.                                                                                                                                    |
| `mcp`             | Отдаёт каждую команду как инструмент Model Context Protocol. См. **Подключение агента для программирования**.                                                                                                                                     |

## Правка: документы, таблицы, презентации

`ieumoffice docs`, `ieumoffice sheet` и `ieumoffice slides` читают и пишут по тому же пути записи, что и приложение, и у них общий словарь: одна **op** — это отдельная правка, а **spec** — это список op, применяемых по порядку.

```sh
ieumoffice sheet read report.xlsx
ieumoffice slides apply deck.pptx --ops ops.json --dry-run
ieumoffice docs apply brief.docx --ops ops.json
```

`--dry-run` сообщает, что сделала бы пакетная операция, и ничего не пишет — это дешёвый способ проверить spec до того, как он применится. Панель ИИ в приложении работает ровно на этих op, поэтому всё, что можно попросить у неё, можно и запрограммировать.

## Команды поиска, изображений и медиа

`search`, `image` и `media` используют то, что настроено в приложении в разделе Настройки ▸ ИИ ▸ Дополнительно:

- `search` работает всегда. По умолчанию используется бесплатный поиск либо поисковый провайдер, чей ключ вы выбрали.
- `image` нужен ключ провайдера изображений. В этой версии подписка не создаёт изображения.
- `media` для изображения использует провайдера с ключом, если он настроен. Вашу подписку Claude или Codex она использует, только если вы это разрешили, а по умолчанию это **выключено**; переключатель и его ограничения описаны в статье [Подключение ИИ-агента](help://mcp).
- `media` для видео или аудио нужен провайдер с ключом, который поддерживает видео.

`ieumoffice capabilities --json` сообщает всё это, не вызывая ни один ИИ. В его `detail` содержится:

| Поле                                                                             | Что сообщает                                                                                                                                                                                                                             |
| -------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `search`, `image_search`, `image_generation`, `image_analysis`, `video_analysis` | Для каждой функции: `available`; `via` — кто отвечает; `route` — одно из `free`, `key` или `subscription`; `metered: true` для входа с оплатой по расходу; а когда функция недоступна — `message`, текст, которым отвечает сама команда. |
| `media_analysis`                                                                 | Сохранено для старых скриптов: то же, что `image_analysis`, либо `video_analysis`, когда работает только видео.                                                                                                                          |
| `automatic_calls`                                                                | `subscription_enabled`, а пока он включён — `used`, число автоматических запросов за последний час (только для сведения); `limit` и `remaining` всегда `null`.                                                                           |
| `app`                                                                            | `available`: установлено ли приложение там, где команда может его запустить.                                                                                                                                                             |
| `settings_path`                                                                  | Файл настроек, из которого прочитаны эти ответы.                                                                                                                                                                                         |

Когда `image` или `media` не может выполниться, команда завершается с кодом 4 и `error: "app_unavailable"`, а `detail.errorCode` сообщает причину. `unavailable` означает, что для функции ничего не настроено, поэтому повторная попытка не поможет. `rate-limit` сопровождается `detail.resetsAt` — временем (в миллисекундах), когда запросы снова станут возможны.

## Что она хранит на этом компьютере

Оба файла лежат в папке `.ieumoffice` внутри вашей пользовательской папки:

- `~/.ieumoffice/launcher` записывает, где находится команда приложения, чтобы агент для программирования нашёл её, даже когда её нет в вашем `PATH`.
- `~/.ieumoffice/cli-audit.jsonl` получает по одной строке на каждую выполненную команду — команда, её аргументы и результат, — так что потом можно посмотреть, что делал агент.

## Model Context Protocol

`ieumoffice mcp` отдаёт каждую команду как инструмент MCP, а `ieumoffice mcp install <agent|all>` регистрирует его в собственной конфигурации агента для программирования. Об этой стороне — см. **Подключение агента для программирования**.

## Чего команда не делает

Она читает и пишет файл. Это не приложение: окна нет, а диалог обновления внутри приложения здесь не действует. Всё, что требует окна — панель ИИ, проверка качества отрендеренного слайда, — должно дождаться, пока вы откроете файл. `ieumoffice render` даёт вам пиксели и без окна, а `ieumoffice slides` сама проверяет вёрстку презентации.
