# PDF-Werkzeuge

Ein Fenster für alltägliche PDF-Aufgaben, das bei der Aufgabe beginnt. Das Ergebnis wird immer als neue Datei gespeichert, das Original bleibt unverändert. Die Werkzeuge in diesem Fenster arbeiten nur auf diesem PC und nutzen keine KI.

## So funktioniert es

1. Klicken Sie auf der Startseite auf die Karte **PDF-Werkzeuge**. Ein eigenes Fenster öffnet sich.
2. Wählen Sie eine Aufgabe, die nötigen Dateien und die Optionen, und klicken Sie auf **Als neue Datei speichern**.
3. Nach dem Speichern zeigt **In einem Tab öffnen** das Ergebnis sofort, und **Im Ordner anzeigen** öffnet den Ordner.

## Die Werkzeuge

| Gruppe               | Werkzeuge                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Seiten ordnen        | PDFs zusammenführen, PDF aufteilen, Seiten als PDF extrahieren, Reihenfolge umkehren, Alle drehen, Leere Seiten entfernen |
| Druck vorbereiten    | Für Duplexdruck ausgleichen, Seiten zusammenfassen, Seitengröße, Seiten teilen                                            |
| Gestalten            | Hintergrund hinzufügen                                                                                                    |
| Bereinigen           | Anmerkungen entfernen                                                                                                     |
| Umwandeln            | Bilder zu PDF, Als Text speichern                                                                                         |
| Größe und Sicherheit | Verkleinern, Passwort hinzufügen, Passwort entfernen, Datei reparieren                                                    |
| Im PDF-Editor        | Wasserzeichen & Kopf-/Fußzeile, Seiten zuschneiden, Bilder exportieren, PDF umwandeln, Bearbeiten, signieren, schwärzen   |

Die Karten unter **Im PDF-Editor** öffnen das gewählte PDF in einem Editor-Tab. Wählen Sie den Befehl dort im Menüband.

## Gut zu wissen

- Sie können nicht über eine Quelldatei speichern oder über eine Datei, die mit ungespeicherten Änderungen geöffnet ist.
- Ein passwortgeschütztes PDF lässt sich in den anderen Werkzeugen erst nach **Passwort entfernen** verwenden. Eine Datei, deren Passwort Sie nicht kennen, lässt sich nicht öffnen.
- **Datei reparieren** holt nur die Teile zurück, die noch lesbar sind. Öffnen Sie die neue Datei und prüfen Sie, ob keine Seite fehlt.
- **Leere Seiten entfernen** zeigt nur Kandidaten. Entfernt werden nur die gewählten Seiten, und eine Seite mit auch nur einem Zeichen ist nie ein Kandidat.
- **Anmerkungen entfernen** behält Formularfelder und entfernt Links nur, wenn Sie sie ankreuzen. Der Inhalt entfernter Anmerkungen bleibt nicht in der neuen Datei.
- **Als Text speichern** liest nur die Textebene. Seiten, deren Text ein Bild ist, etwa gescannte Seiten, bleiben leer.

## Wofür es sich eignet

| Situation                                                                              | Werkzeuge                                           |
| -------------------------------------------------------------------------------------- | --------------------------------------------------- |
| Mehrere Dokumente auf einmal beidseitig drucken, jedes auf einer Vorderseite beginnend | Für Duplexdruck ausgleichen → Seiten zusammenfassen |
| Ein gescanntes Dokument hat die umgekehrte Reihenfolge oder liegende Seiten            | Reihenfolge umkehren, Alle drehen                   |
| Zwischen den Seiten eines gescannten Stapels stecken leere Seiten                      | Leere Seiten entfernen                              |
| Den Briefkopf einer Firma oder Einrichtung auf jede Seite legen                        | Hintergrund hinzufügen                              |
| Vor dem Versand eines geprüften Dokuments die Kommentare bereinigen                    | Anmerkungen entfernen                               |
| Mehrere Fotos als ein PDF abgeben                                                      | Bilder zu PDF                                       |
| Den Text eines PDFs in einem anderen Dokument weiterverwenden                          | Als Text speichern                                  |
| Ein PDF ist zu groß für den Anhang einer E-Mail                                        | Verkleinern                                         |
| Ein PDF, dessen Download abgebrochen ist, lässt sich nicht öffnen                      | Datei reparieren                                    |
