# 글꼴: 시스템 글꼴과 글꼴 파일 설치

## 글꼴 목록

글꼴 컨트롤은 각 편집기의 홈 탭에 있습니다.

각 편집기의 글꼴 선택기는 다음을 합쳐 보여 줍니다. 로컬에 설치된 글꼴과 플랫폼에서 흔한 후보(Windows와 macOS의 일반적인 문자 체계, CJK 글꼴이 자기 시스템에서 보고하는 현지화 이름까지 포함). 시스템이 로컬 글꼴을 나열할 수 있으면 실제로 있는 것으로 묶고, 할 수 없으면 후보 전체 목록으로 낮춥니다.

목록에 나오는 글꼴은 이 PC에 설치된 것이거나 앱에 함께 들어 있는 것입니다. 내려받는 글꼴은 없습니다.

## 글꼴 파일 설치(Slides)

- Slides 글꼴 목록 맨 아래의 **글꼴 파일 설치…**로 가지고 있는 글꼴 파일(.ttf, .otf, .ttc, .otc)을 추가합니다.
- 파일은 앱 전용 글꼴 폴더로 복사됩니다. 이 앱에서만 쓰이고 시스템에는 설치되지 않습니다. 열려 있는 프레젠테이션은 새 글꼴로 다시 배치됩니다.
- 파일에 든 글꼴 계열이 하나뿐이면 선택해 둔 곳에 바로 적용됩니다.
- 이렇게 설치한 글꼴은 목록에 나오지 않습니다. 나중에 쓰려면 글꼴 입력란에 이름을 직접 입력합니다.
- 같은 계열의 굵기 여러 개를 함께 설치해 둘 수 있습니다.
- 이렇게 설치한 글꼴을 지우는 기능은 앱에 없습니다.

## 문서에 쓰였지만 내 PC에 없는 글꼴

- 설치되지 않은 글꼴을 쓴 문서는 대체 글꼴로 보여 줍니다.
