# เครื่องมือ PDF

หน้าต่างสำหรับงาน PDF ที่ใช้บ่อย โดยเริ่มจากเลือกงานที่จะทำ ผลลัพธ์จะบันทึกเป็นไฟล์ใหม่เสมอ และไฟล์ต้นฉบับจะไม่เปลี่ยน เครื่องมือในหน้าต่างนี้ทำงานบนพีซีเครื่องนี้เท่านั้นและไม่ใช้ AI

## วิธีใช้

1. ในหน้าแรก คลิกการ์ด **เครื่องมือ PDF** หน้าต่างแยกจะเปิดขึ้น
2. เลือกงาน เลือกไฟล์ที่ต้องใช้และตัวเลือก แล้วคลิก **บันทึกเป็นไฟล์ใหม่**
3. หลังบันทึก **เปิดในแท็บ** จะแสดงผลลัพธ์ทันที และ **แสดงในโฟลเดอร์** จะเปิดโฟลเดอร์ของไฟล์

## เครื่องมือ

| กลุ่ม              | เครื่องมือ                                                                       |
| ------------------ | -------------------------------------------------------------------------------- |
| จัดระเบียบหน้า     | รวม PDF, แยก PDF, แยกหน้าเป็น PDF, เรียงย้อนกลับ, หมุนทั้งหมด, ลบหน้าว่าง        |
| เตรียมพิมพ์        | เตรียมพิมพ์สองหน้า, รวมหน้า, ขนาดหน้า, แยกหน้า                                   |
| ตกแต่ง             | เพิ่มพื้นหลัง                                                                    |
| จัดระเบียบ         | ลบคำอธิบายประกอบ                                                                 |
| แปลง               | รูปภาพเป็น PDF, บันทึกเป็นข้อความ                                                |
| ขนาดและความปลอดภัย | ลดขนาด, ใส่รหัสผ่าน, เอารหัสผ่านออก, ซ่อมไฟล์                                    |
| ในตัวแก้ไข PDF     | ลายน้ำและหัว/ท้ายกระดาษ, ครอบตัดหน้า, ส่งออกรูปภาพ, แปลง PDF, แก้ไข ลงนาม ปิดทับ |

การ์ดในกลุ่ม **ในตัวแก้ไข PDF** จะเปิด PDF ที่เลือกในแท็บตัวแก้ไข เลือกคำสั่งนั้นจาก Ribbon ที่นั่น

## ควรรู้

- บันทึกทับไฟล์ต้นฉบับ หรือทับไฟล์ที่เปิดอยู่และมีการเปลี่ยนแปลงที่ยังไม่บันทึกไม่ได้
- PDF ที่มีรหัสผ่านจะใช้กับเครื่องมืออื่นได้หลังจาก**เอารหัสผ่านออก**ก่อน ไฟล์ที่คุณไม่รู้รหัสผ่านจะเปิดไม่ได้
- **ซ่อมไฟล์**กู้คืนได้เฉพาะส่วนที่ยังอ่านได้ โปรดเปิดไฟล์ใหม่และตรวจว่าไม่มีหน้าใดหายไป
- **ลบหน้าว่าง** แสดงเพียงหน้าที่น่าจะว่าง ระบบลบเฉพาะหน้าที่เลือก และหน้าที่มีตัวอักษรแม้แต่ตัวเดียวจะไม่ถูกเสนอ
- **ลบคำอธิบายประกอบ** จะเก็บช่องกรอกฟอร์มไว้ และลบลิงก์เฉพาะเมื่อเลือก เนื้อหาของคำอธิบายประกอบที่ลบจะไม่อยู่ในไฟล์ใหม่
- **บันทึกเป็นข้อความ** อ่านเฉพาะชั้นข้อความ หน้าที่ข้อความเป็นรูปภาพ เช่น หน้าที่สแกน จะว่างเปล่า

## ลองใช้เมื่อ

| สถานการณ์                                                              | เครื่องมือ                   |
| ---------------------------------------------------------------------- | ---------------------------- |
| พิมพ์เอกสารหลายฉบับแบบสองหน้าพร้อมกัน และแต่ละฉบับต้องเริ่มที่ด้านหน้า | เตรียมพิมพ์สองหน้า → รวมหน้า |
| เอกสารที่สแกนเรียงกลับด้านหรือมีหน้าตะแคง                              | เรียงย้อนกลับ, หมุนทั้งหมด   |
| มีหน้าว่างแทรกอยู่ระหว่างหน้าของชุดเอกสารที่สแกน                       | ลบหน้าว่าง                   |
| ใส่หัวจดหมายของบริษัทหรือหน่วยงานลงในทุกหน้า                           | เพิ่มพื้นหลัง                |
| จัดการความคิดเห็นก่อนส่งเอกสารที่ตรวจแล้ว                              | ลบคำอธิบายประกอบ             |
| ส่งรูปถ่ายหลายรูปเป็น PDF ไฟล์เดียว                                    | รูปภาพเป็น PDF               |
| นำข้อความใน PDF ไปใช้ในเอกสารอื่น                                      | บันทึกเป็นข้อความ            |
| PDF ใหญ่เกินกว่าจะแนบไปกับอีเมล                                        | ลดขนาด                       |
| PDF ที่ดาวน์โหลดค้างกลางทางเปิดไม่ได้                                  | ซ่อมไฟล์                     |
