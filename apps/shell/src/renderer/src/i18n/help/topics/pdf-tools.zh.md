# PDF 工具

这个窗口从要做的事开始，处理常见的 PDF 任务。结果总是另存为新文件，原文件不会改变。此窗口中的工具只在这台电脑上处理，不使用 AI。

## 使用步骤

1. 在主页点击 **PDF 工具** 卡片，会打开一个单独的窗口。
2. 选择任务，选择所需的文件并设置选项，然后点击 **另存为新文件**。
3. 保存后，用 **在标签页中打开** 立即查看结果，或用 **打开所在文件夹** 打开文件所在位置。

## 工具列表

| 分组            | 工具                                                                     |
| --------------- | ------------------------------------------------------------------------ |
| 整理页面        | 合并 PDF、拆分 PDF、抽取页面为 PDF、倒序排列、全部旋转、查找并删除空白页 |
| 打印准备        | 双面打印对齐、合并页面、页面大小、拆分页面                               |
| 装饰            | 叠加背景                                                                 |
| 整理            | 批量删除注释                                                             |
| 转换            | 图片转 PDF、保存为文本                                                   |
| 大小与安全      | 压缩大小、添加密码、移除密码、修复文件                                   |
| 在 PDF 编辑器中 | 水印与页眉页脚、裁剪页面、导出图片、PDF 转换、编辑、签名、涂黑           |

**在 PDF 编辑器中** 分组中的卡片会在编辑器标签页中打开所选 PDF。请在功能区中选择相应功能。

## 须知

- 不能保存到原文件，也不能保存到带有未保存更改且正在打开的文件。
- 有密码保护的 PDF 需要先用**移除密码**去掉密码，才能在其他工具中使用。不知道密码的文件无法打开。
- **修复文件**只能找回仍可读取的部分。请打开新文件，确认没有缺页。
- **查找并删除空白页** 只列出候选页面。只删除您选中的页面，有任何文字的页面都不会成为候选。
- **批量删除注释** 不会删除表单域，链接只有在勾选时才删除。已删除注释的内容不会留在新文件中。
- **保存为文本** 只读取文字层。文字以图片形式存在的页面（如扫描页）将为空。

## 可以这样用

| 情况                                     | 使用的工具              |
| ---------------------------------------- | ----------------------- |
| 一次双面打印多份文件，每份都要从正面开始 | 双面打印对齐 → 合并页面 |
| 扫描的文件顺序颠倒，或页面横了过来       | 倒序排列、全部旋转      |
| 扫描的一叠文件中夹着空白页               | 查找并删除空白页        |
| 给每一页加上公司或机构的信纸背景         | 叠加背景                |
| 发送审阅完的文件前整理批注               | 批量删除注释            |
| 把多张照片合成一个 PDF 提交              | 图片转 PDF              |
| 把 PDF 中的文字用到其他文档里            | 保存为文本              |
| PDF 太大，无法作为邮件附件发送           | 压缩大小                |
| 下载中断的 PDF 打不开                    | 修复文件                |
