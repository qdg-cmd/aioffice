# 字型：系統字型與安裝字型檔

## 字型清單

字型控制項位於各編輯器的「常用」分頁。

每個編輯器的字型選擇器都會合併顯示：本機已安裝的字型＋平台常見的候選字型（Windows 與 macOS 上常見的西文與中日韓字型家族，包含中日韓字型在各自系統上回報的本機化名稱）。當系統能列舉本機字型時，清單會依實際存在的內容分組；無法列舉時則退回完整的候選清單。

清單裡的每個字型，不是已經安裝在這台電腦上，就是隨應用程式一起提供的。不會下載任何東西。

## 安裝字型檔（Slides）

- 在 Slides 字型清單的最底下，**安裝字型檔案…** 可以加入你手邊已有的字型檔：.ttf、.otf、.ttc 或 .otc。
- 這些檔案會複製到應用程式自己的字型資料夾。它們只能在這個應用程式裡使用，不會安裝到系統。已開啟的簡報會以新字型重新排版。
- 如果這些檔案裡只有一個字型家族，它會立刻套用到你目前選取的內容上。
- 以這種方式安裝的字型不會出現在清單裡。之後要用，請在字型方塊中輸入它的名稱。
- 同一家族的多種字重可以同時安裝。
- 應用程式沒有移除這類字型的命令。

## 文件需要但你沒有的字型

- 文件用到尚未安裝的字型時，會以替代字型顯示。

## 中文排版

- Docs 中的中文字型支援與 Word 對齊的標點壓縮與避頭尾斷行規則（見 Docs 章）。
