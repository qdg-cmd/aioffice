# フォント：システムフォントとフォントファイルのインストール

## フォントの一覧

フォントのコントロールは各エディターのホームタブにあります。

各エディターのフォント選択は次をまとめて表示します。ローカルにインストール済みのフォントと、プラットフォームで一般的な候補（Windows と macOS の一般的な欧字系・中日韓のファミリー、および CJK フォントが自分のシステムで報告するローカライズ名を含む）。システムがローカルのフォントを列挙できる場合は実際に存在するものでグループ化し、できない場合は候補の完全な一覧にフォールバックします。

一覧に表示されるフォントは、この PC にインストールされているか、アプリに同梱されているかのどちらかです。ダウンロードされるものはありません。

## フォントファイルのインストール（Slides）

- Slides のフォント一覧のいちばん下にある **フォントファイルをインストール…** から、手元にあるフォントファイル（.ttf、.otf、.ttc、.otc）を追加できます。
- ファイルはアプリ専用のフォントフォルダーにコピーされます。このアプリの中でだけ使え、システムには何もインストールされません。開いているプレゼンテーションは、新しいフォントでレイアウトし直されます。
- ファイルに含まれるフォントファミリーが 1 つだけなら、選択中の箇所にすぐ適用されます。
- この方法でインストールしたフォントは一覧に表示されません。あとで使うときは、フォントのボックスに名前を入力します。
- 同じファミリーの複数のウェイトを並べてインストールできます。
- この方法でインストールしたフォントを削除するコマンドは、アプリにはありません。

## 文書に必要なのに手元にないフォント

- インストールされていないフォントを使っている文書は、代替フォントで表示されます。

## 中日韓の組版

- Docs で CJK フォントを使うと、Word と揃った約物圧縮と行頭行尾の禁則が適用されます（Docs の章を参照）。
