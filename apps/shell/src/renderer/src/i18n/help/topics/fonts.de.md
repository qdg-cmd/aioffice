# Schriften: Systemschriften und Installation von Schriftdateien

## Die Schriftlisten

Die Schriftsteuerelemente liegen auf der Startseite jedes Editors.

Die Schriftauswahl jedes Editors führt zusammen: lokal installierte Schriften + die üblichen Kandidaten der Plattform (die gängigen Familien unter Windows und macOS, lateinisch und ostasiatisch, einschließlich der lokalisierten Namen, unter denen ostasiatische Schriften ihr Heimat-System melden). Wenn das System lokale Schriften aufzählen kann, gruppiert die Liste nach dem, was tatsächlich vorhanden ist; sonst weicht sie auf die vollständige Kandidatenliste aus.

Jede Schrift in der Liste ist entweder auf diesem PC installiert oder wird mit der App geliefert. Heruntergeladen wird nichts.

## Eine Schriftdatei installieren (Slides)

- Am Ende der Schriftliste von Slides fügt **Schriftdatei installieren…** Schriftdateien hinzu, die Sie bereits haben: .ttf, .otf, .ttc oder .otc.
- Die Dateien werden in den eigenen Schriftenordner der App kopiert. Sie funktionieren nur in dieser App; im System wird nichts installiert. Geöffnete Präsentationen werden mit der neuen Schrift neu gesetzt.
- Enthalten die Dateien eine einzige Schriftfamilie, wird sie sofort auf Ihre Auswahl angewendet.
- Eine so installierte Schrift erscheint nicht in der Liste. Um sie später zu verwenden, tippen Sie ihren Namen in das Schriftfeld.
- Mehrere Stärken einer Familie können nebeneinander installiert werden.
- Die App hat keinen Befehl, um eine so installierte Schrift wieder zu entfernen.

## Schriften, die ein Dokument braucht, die Sie aber nicht haben

- Ein Dokument, das eine nicht installierte Schrift verwendet, wird mit einer Ersatzschrift angezeigt.

## Ostasiatische Typografie

- Ostasiatische Schriften erhalten in Docs die mit Word abgestimmte Zeichensatzkompression und Kinsoku-Zeilenregeln (siehe das Docs-Kapitel).
