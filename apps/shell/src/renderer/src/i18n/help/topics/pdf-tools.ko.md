# PDF 도구

PDF로 자주 하는 일을 할 일부터 골라 처리하는 창입니다. 결과는 언제나 새 파일로 저장되고 원본은 바뀌지 않습니다. 이 창의 도구는 이 PC 안에서만 처리하며 AI를 쓰지 않습니다.

## 쓰는 순서

1. 홈 화면에서 **PDF 도구** 카드를 누릅니다. 별도 창이 뜹니다.
2. 할 일을 고르고, 필요한 파일을 고른 뒤 옵션을 정하고 **새 파일로 저장**을 누릅니다.
3. 저장한 뒤 **탭에서 열기**로 결과를 바로 보거나 **폴더 열기**로 파일이 있는 곳을 엽니다.

## 도구 목록

| 묶음           | 도구                                                                                 |
| -------------- | ------------------------------------------------------------------------------------ |
| 페이지 정리    | PDF 병합, PDF 분할, 페이지를 PDF로 추출, 역순 정렬, 모두 회전, 빈 페이지 찾아 지우기 |
| 인쇄 준비      | 양면 인쇄 맞추기, 페이지 모아찍기, 페이지 크기, 페이지 분할                          |
| 꾸미기         | 배경 겹치기                                                                          |
| 정리하기       | 주석 한꺼번에 지우기                                                                 |
| 변환           | 이미지로 PDF 만들기, 텍스트로 저장                                                   |
| 용량·보안      | 용량 줄이기, 암호 걸기, 암호 풀기, 파일 복구                                         |
| PDF 편집기에서 | 워터마크 및 머리글/바닥글, 페이지 자르기, 이미지 내보내기, PDF 변환, 편집·서명·가림  |

**PDF 편집기에서** 묶음의 카드는 고른 PDF를 편집기 탭에서 엽니다. 리본에서 그 기능을 고르세요.

## 알아 둘 것

- 원본 파일이나, 저장하지 않은 변경이 있는 채 열려 있는 파일에는 저장할 수 없습니다.
- 암호가 걸린 PDF는 먼저 **암호 풀기**로 풀어야 다른 도구에서 쓸 수 있습니다. 암호를 모르는 파일은 풀 수 없습니다.
- **파일 복구**는 읽을 수 있는 부분만 되살립니다. 새 파일을 열어 빠진 페이지가 없는지 확인하세요.
- **빈 페이지 찾아 지우기**는 후보를 보여 줄 뿐입니다. 고른 페이지만 지우고, 글자가 한 글자라도 있는 페이지는 후보에 나오지 않습니다.
- **주석 한꺼번에 지우기**는 입력란을 지우지 않고, 링크는 고를 때만 지웁니다. 지운 주석의 내용은 새 파일에 남지 않습니다.
- **텍스트로 저장**은 글자 층만 읽습니다. 스캔한 페이지처럼 글자가 그림인 페이지는 비어 있게 됩니다.

## 이렇게 써 보세요

| 상황                                                                | 쓰는 도구                          |
| ------------------------------------------------------------------- | ---------------------------------- |
| 여러 문서를 한 번에 양면 인쇄하는데 문서마다 앞면에서 시작해야 한다 | 양면 인쇄 맞추기 → 페이지 모아찍기 |
| 스캔한 문서의 순서가 거꾸로 되었거나 페이지가 누웠다                | 역순 정렬, 모두 회전               |
| 스캔한 묶음 사이사이에 빈 페이지가 끼어 있다                        | 빈 페이지 찾아 지우기              |
| 회사나 기관의 바탕 디자인(레터헤드)을 모든 페이지에 입힌다          | 배경 겹치기                        |
| 검토가 끝난 문서를 보내기 전에 메모를 정리한다                      | 주석 한꺼번에 지우기               |
| 사진 여러 장을 PDF 하나로 제출한다                                  | 이미지로 PDF 만들기                |
| PDF의 글을 다른 문서에 옮겨 쓴다                                    | 텍스트로 저장                      |
| 메일에 붙이기에 PDF가 너무 크다                                     | 용량 줄이기                        |
| 내려받다 끊긴 PDF가 열리지 않는다                                   | 파일 복구                          |
