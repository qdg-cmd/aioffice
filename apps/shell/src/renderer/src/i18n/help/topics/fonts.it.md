# Caratteri: font di sistema e installazione di file di font

## Gli elenchi dei caratteri

I controlli dei caratteri si trovano nella scheda Home di ogni editor.

Il selettore dei caratteri di ogni editor unisce: i caratteri installati localmente + i candidati comuni della piattaforma (le famiglie più diffuse di Windows e macOS, western e CJK, compresi i nomi localizzati con cui i caratteri CJK si presentano sui propri sistemi). Quando il sistema riesce a enumerare i caratteri locali l'elenco viene raggruppato in base a ciò che esiste davvero; in caso contrario ricade sull'elenco completo dei candidati.

Ogni carattere dell'elenco è installato su questo PC oppure fornito con l'app. Non viene scaricato nulla.

## Installare un file di carattere (Slides)

- In fondo all'elenco dei caratteri di Slides, **Installa file di carattere…** aggiunge file di caratteri che hai già: .ttf, .otf, .ttc o .otc.
- I file vengono copiati nella cartella dei caratteri propria dell'app. Funzionano solo in questa app; nel sistema non viene installato nulla. Le presentazioni aperte vengono reimpaginate con il nuovo carattere.
- Quando i file contengono una sola famiglia di caratteri, questa viene applicata subito a ciò che hai selezionato.
- Un carattere installato in questo modo non compare nell'elenco. Per usarlo in seguito, digita il suo nome nella casella del carattere.
- Più pesi di una stessa famiglia possono essere installati fianco a fianco.
- L'app non ha un comando per rimuovere un carattere installato in questo modo.

## Caratteri che un documento richiede ma che non hai

- Un documento che usa un carattere non installato viene mostrato con un carattere sostitutivo.

## Tipografia CJK

- I caratteri CJK in Docs ottengono la compressione della punteggiatura e le regole di interruzione di linea (kinsoku) allineate a Word (vedi il capitolo su Docs).
