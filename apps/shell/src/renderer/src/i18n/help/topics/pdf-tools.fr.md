# Outils PDF

Une fenêtre pour les tâches PDF courantes, en partant de la tâche. Le résultat est toujours enregistré dans un nouveau fichier et l’original n’est pas modifié. Les outils de cette fenêtre travaillent uniquement sur ce PC et n’utilisent pas l’IA.

## Fonctionnement

1. Sur l’accueil, cliquez sur la carte **Outils PDF**. Une fenêtre distincte s’ouvre.
2. Choisissez une tâche, les fichiers dont elle a besoin et ses options, puis cliquez sur **Enregistrer comme nouveau fichier**.
3. Après l’enregistrement, **Ouvrir dans un onglet** affiche le résultat et **Afficher dans le dossier** ouvre son dossier.

## Les outils

| Groupe                | Outils                                                                                                                     |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Organiser les pages   | Fusionner des PDF, Diviser le PDF, Extraire les pages en PDF, Inverser l’ordre, Tout pivoter, Supprimer les pages blanches |
| Préparer l’impression | Préparer le recto verso, Fusionner les pages, Taille de page, Diviser les pages                                            |
| Décorer               | Ajouter un arrière-plan                                                                                                    |
| Nettoyer              | Supprimer les annotations                                                                                                  |
| Convertir             | Images en PDF, Enregistrer en texte                                                                                        |
| Taille et sécurité    | Réduire la taille, Ajouter un mot de passe, Retirer le mot de passe, Réparer le fichier                                    |
| Dans l’éditeur PDF    | Filigrane et en-tête/pied de page, Rogner les pages, Exporter les images, Convertir le PDF, Modifier, signer, caviarder    |

Les cartes de **Dans l’éditeur PDF** ouvrent le PDF choisi dans un onglet de l’éditeur. Choisissez-y la commande dans le ruban.

## À savoir

- Impossible d’enregistrer sur un fichier source ou sur un fichier ouvert avec des modifications non enregistrées.
- Un PDF protégé par mot de passe ne s’utilise dans les autres outils qu’après **Retirer le mot de passe**. Un fichier dont vous ne connaissez pas le mot de passe ne peut pas être ouvert.
- **Réparer le fichier** ne récupère que les parties encore lisibles. Ouvrez le nouveau fichier et vérifiez qu’il ne manque aucune page.
- **Supprimer les pages blanches** ne fait que montrer des candidates. Seules les pages choisies sont supprimées, et une page avec au moins un caractère n’est jamais proposée.
- **Supprimer les annotations** conserve les champs de formulaire et ne supprime les liens que si vous les cochez. Le contenu des annotations supprimées ne reste pas dans le nouveau fichier.
- **Enregistrer en texte** ne lit que la couche de texte. Les pages dont le texte est une image, comme les pages numérisées, seront vides.

## Exemples d’usage

| Situation                                                                             | Outils à utiliser                             |
| ------------------------------------------------------------------------------------- | --------------------------------------------- |
| Imprimer plusieurs documents en recto verso d’un coup, chacun commençant sur un recto | Préparer le recto verso → Fusionner les pages |
| Un document numérisé est dans l’ordre inverse ou a des pages couchées                 | Inverser l’ordre, Tout pivoter                |
| Des pages blanches se sont glissées dans une liasse numérisée                         | Supprimer les pages blanches                  |
| Appliquer le papier à en-tête d’une entreprise ou d’un organisme sur chaque page      | Ajouter un arrière-plan                       |
| Nettoyer les commentaires avant d’envoyer un document relu                            | Supprimer les annotations                     |
| Remettre plusieurs photos sous forme d’un seul PDF                                    | Images en PDF                                 |
| Reprendre le texte d’un PDF dans un autre document                                    | Enregistrer en texte                          |
| Un PDF est trop lourd pour être joint à un e-mail                                     | Réduire la taille                             |
| Un PDF dont le téléchargement s’est interrompu ne s’ouvre pas                         | Réparer le fichier                            |
