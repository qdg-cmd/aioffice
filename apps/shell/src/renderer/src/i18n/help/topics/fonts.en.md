# Fonts: system fonts and installing font files

## The font lists

The font controls live on each editor's Home tab.

Each editor's font picker merges: locally installed fonts + platform-common candidates (the usual Windows and macOS families, Western and CJK, including the localized names CJK fonts report on their home systems). When the system can enumerate local fonts the list groups by what actually exists; otherwise it degrades to the full candidate list.

Every font in the list is either installed on this PC or shipped with the app. Nothing is downloaded.

## Installing a font file (Slides)

- At the bottom of the Slides font list, **Install font file…** adds font files you already have: .ttf, .otf, .ttc or .otc.
- The files are copied into the app's own font folder. They work in this app only; nothing is installed into the system. Open presentations are laid out again with the new font.
- When the files hold a single font family, it is applied to what you have selected right away.
- A font installed this way does not show up in the list. To use it later, type its name into the font box.
- Several weights of one family can be installed side by side.
- The app has no command for removing a font installed this way.

## Fonts a document needs but you do not have

- A document that uses a font that is not installed is shown with a substitute font.

## CJK typography

- CJK fonts in Docs get Word-aligned punctuation compression and kinsoku line rules (see the Docs chapter).
